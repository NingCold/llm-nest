## 当前云端与桌面生命周期

`cloud-server` 独立运行，不初始化旧 Runtime、AiClient 或 SocialStore。启动读取 PostgreSQL 连接串，完成迁移；邀请 CLI 执行完直接退出。服务模式再校验公开来源、附件与静态目录、邮件配置并监听 HTTP，生产通过反向代理提供 HTTPS。SIGINT 触发 HTTP 优雅关闭；数据库和附件由部署独立持久化。环境变量和容器入口见[云端服务](../../server/cloud/README.md)。

CloudApp 是 Web/Tauri 默认入口。浏览器请求同源云端 API；桌面的 CloudState 原生网络层负责服务器选择、JSON、SSE 和附件传输，不通过 SocialFeature 执行业务。Cookie 默认只在桌面进程内存，Windows 显式保持登录后以当前用户 DPAPI 保护令牌，重启先联网验证会话；非 Windows 原生端暂不支持。登录与本机 SDK 解锁分开，详见[账号设计](accounts.md#登录会话与本机解锁)。云端服务器地址与草稿按客户端规则保存；`CLOUD_CA_CERT_FILE` 仅给授权测试站点增加 CA，不取消 TLS 验证。

桌面已移除旧 Runtime、SocialFeature、旧本地 IPC 与 worker 入口，不加载旧 SQLite 或模型配置。关闭先等待草稿保存，页面重载或销毁释放云端订阅。云端服务不受客户端退出影响。独立本机 `llmn-agent` 可由 CLI 或桌面原生层配置、配对与启停。关闭窗口先保存草稿；存在本机运行或待配对工作时，首次提供继续后台、停止并退出和取消三个选项，后续关闭隐藏到托盘。

## 云端与 Agent 生命周期

按[云端计划](../project/cloud-plan.md)，客户端、服务端、自带 Agent 独立运行，连接器可单独引用；当前实际仍为单仓，不共享一个运行时生命周期。下一轮按[拆仓计划](../project/repository-split-plan.md)分为三仓，连接器暂在服务端仓独立维护。独立云端服务、AI 节点与客户端私聊、群聊已接通；节点意识资料和云端接话与约定已接入；在线角色/模型管理与桌面后台集成使用下述独立节点生命周期。

| 运行部分 | 资源与职责 | 生命周期 |
| --- | --- | --- |
| 云端社交服务 | PostgreSQL 中的账号、认证、权限、关系、聊天、社交任务和事件；附件独立持久目录；HTTPS/SSE 与节点 WSS | 独立于所有客户端与节点；不加载 AiClient 或节点模型配置，不保存模型 Key |
| 自带 Agent | 本地 SQLite 中的 persona、模型参数、记忆、每 AI/窗口摘要和执行检查点；AiClient、模型配置/凭据解析、内部并发与预算 | 可无聊天界面独立启动；主动连云端，无入站端口，一个节点可运行多个 AI |
| Web/桌面客户端 | 同一云端 HTTPS JSON/SSE；按服务器和实际账号隔离的缓存、草稿和游标 | 关闭客户端不关闭云端或远程节点；桌面 IPC 仅负责系统能力与本机 Agent 管理 |
| 连接器 | 当前 v4 的握手、任务通知/取消、授权材料、开始/结果与意识管理；重连补齐来源并重读任务 | 协议库可由外部 Agent 引用，不依赖完整 Runtime、AiClient 或意识服务 |

### 启动与配置

云端首轮在单台 Linux 服务器容器运行一个社交服务，使用 PostgreSQL，附件独立目录与数据库一起备份；HTTPS 为客户端和节点提供入口，邮件通过可配置发送服务接入。不拆微服务，不建立服务器互联。

Agent 启动先取得本地存储锁，读取配置、凭据引用与执行检查点，再通过节点专用凭据握手，确认协议能力和每个 AI 的有效绑定版本，补齐来源与任务状态后领取新工作。模型 Key 仅在节点本地设置和解析，云端配置不含 Key，云端宿主也不能要求初始化模型客户端才能提供聊天。开始/结果不确定时按[执行契约](execution.md)恢复，不重放可能已发生的调用。

模型选择、思考强度、temperature/max_tokens、persona、记忆和摘要的权威位置均在 Agent。自带 Agent 对节点现有 providers 严格解析模型与生成参数，档案以 SQLite 事务保存，运行冻结配置快照；普通配置修改用于新运行，不改变在飞请求。节点本地意识编辑/遗忘按其来源和版本规则使相关材料与运行失效；云端只负责它掌握的社交来源及授权，不验证外部 Agent 的全部内部算法。

未启用加密的路径中，所有 AI 管理员可发起在线内部资料管理。云端逐次复核管理员与当前绑定后转发，节点保存才返回成功；正文不写云端持久库或日志，Key 根本不经过平台。超时表示结果未确认，保留 requestId 查询/重试，不排队离线修改，不以云端已接收冒充节点已保存。节点离线仍可管理云端公开资料与授权。

### 关闭与撤销

关闭桌面聊天窗口默认让本机 Agent 在后台继续运行，首次关闭说明此行为并提供停止选项，可随时从托盘停止。窗口草稿仍须保存；窗口关闭与 Agent 停止分别完成各自收尾。远程节点独立运行，不受该窗口关闭影响；本机睡眠或关机使本机 AI 离线。开机自启和账号退出对 Agent 的影响不在此处新增产品规则。

显式停止自带 Agent 时结束任务循环与模型流，保留既有持久检查点；已开始且结果不明的调用在重启时按 uncertain 收尾，不自动重调。停止云端服务时排空云端事务与连接。任一进程的退出不声称与其他存储实现分布式原子提交。一个 AI 同时只有一个有效节点，管理员手动换节点后云端撤销旧绑定资格；旧节点迟到提交拒收，意识资料另行迁移，新节点重新配置凭据。

日志仅记录必要 ID、版本、状态与错误分类；节点内部资料转发正文、模型 Key、凭据与完整模型请求不写云端日志。节点上报的使用量不等同可独立核实的费用。

### 桌面原生节点管理

`local_agent_status/setup/pair/start/stop/models` 是固定业务 IPC，不接收任意本机路径、operatorId 或服务器身份。原生层从当前云端会话 `/me` 获取真人账号，按服务器规范 origin 的 SHA256 与真人 UUID 选择 `desktop-agents/<serverHash>/<humanId>`。配置和启动只作用于这一目录；托盘可停止该桌面登记的本机节点，远程节点不受影响。

桌面通过资源目录 `agent/llmn-agent[.exe]` 运行独立程序。init 创建私有目录，check 校验模型和参数，pair-json 仅输出配对资料与绑定结果；运行使用 run-managed。短命命令和待配对进程由原生层拥有，显式退出会取消配对；运行进程可在窗口隐藏或桌面异常退出后继续。进程环境先清空，再注入必要系统变量及配置引用的 Key；Key 不进入命令行或日志。

状态与停止使用节点目录锁和实例 UUID。启动在配置及已配对档案校验后发布描述并输出 ready 确认；原生层收到确认后再查询状态，本机状态查询与启动共用操作互斥，避免查询先占用目录锁。停止请求只匹配当前实例，不依据旧 PID 杀进程。未运行时只读查询已配对 AI，不执行 SQLite 迁移或恢复。普通 CLI run 不作为桌面托管进程停止。显式退出先保存草稿，再停止已登记本机节点和待配对进程；失败保持窗口并显示错误。

在线档案命令在控制帧被 select 接收后完整处理，SQLite 保存与去重不放入可取消的 select 分支。普通配置修改只影响新任务，在飞任务保持原模型与参数。

### 模型目录与固定产物

桌面通过随附 `llmn-agent catalog` 读取内置供应商和模型目录，不传节点目录，不读取旧宿主配置，也不链接模型适配器。JSON 使用连接器的 AgentCatalog 契约，包含 protocolVersion、agentVersion 和 providers；当前协议为 1，不兼容或读取失败明确报错，没有桌面内置目录回退。实际节点配置仍由 Agent 的 `check` 在写入前最终校验。

桌面资源包含固定版本 Agent 和 `agent-artifact.json` 的版本、目标平台与 SHA-256。准备资源只取得明确产物并核验摘要，不隐式构建工作区或兄弟仓源码。开发可显式指定 `LLMN_AGENT_EXECUTABLE`，正常安装使用资源目录中的程序。

客户端目录解析为内部小模块，继续沿用 `LLMN_DATA_DIR` 或用户目录下 `.llmn`；会话材料的 `secure-credentials` 和节点的 `desktop-agents` 位置保持。AppPaths 只报告目录位置，LLMN_CONFIG 可作为旧配置位置提示；不会创建、读取或热更新旧宿主 TOML，也不会为启动云端客户端迁移旧目录。历史数据通过独立迁移工具处理。

### 生命周期与关闭

主窗口先请求当前页面保存草稿，匹配页面与关闭请求才接受确认；最多等待 10 秒。保存或状态检查失败保留窗口。继续后台只隐藏窗口并发出 desktop-close-retained；取消同样解除关闭锁。停止并退出先停止本机 Agent 和配对子进程，成功后退出；云端服务和远程节点独立运行。
