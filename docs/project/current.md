# 当前安排

[已完成](completed.md) · [待验收与候选](backlog.md) · [总计划](cloud-plan.md) · [使用指南](../usage.md)

已完成第 3 步第一批“群聊闭环”：建群、成员与群主/管理员权限、结构化提及与回复、多节点依次接话，以及退出、屏蔽和 AI 停用恢复。当前成员共享完整群历史；私聊屏蔽不影响共同群，停用 AI 保留账号和历史，恢复只响应新消息。

这批已部署到内网测试服务，部署前保留 PostgreSQL 备份。本机独立 Agent 已升级到节点协议 v2，现有账号、档案与聊天沿用。两位真人、两个模拟 AI、两个实际 Agent 进程完成群聊联调，Ubuntu 作为另一台 HTTPS 客户端读历史并回复；Edge 验证了建群、改名、群管理员、提及/回复、草稿刷新恢复、屏蔽与启停。数据库、节点、连接器、前端检查及私聊恢复回归均通过，详见[群聊验证](../validation/README.md#云端群聊验证)。本轮没有调用真实模型。

下一批是**第 3 步第二批：意识系统接入**。云端继续保存原文、附件和来源版本；节点保存每个 AI 的显式记忆、各窗口摘要，并接入共同群话题到私聊的引用及来源失效。完成标准是：同一个 AI 能带着允许引用的群话题继续私聊，记忆和摘要按 AI/窗口隔离，编辑、撤回、退群或遗忘后不再使用失效材料。

第三批再迁入有限自动接话、暂停/结束、一次性约定联系、免打扰与额度。在线内部配置、管理员名单界面和桌面一键运行/托盘保持第 4 步，旧数据备份预览与迁移保持第 5 步，具体范围只在[总计划](cloud-plan.md#第-3-步群聊与意识系统)维护。

第 1 步的邀请注册、真人聊天和第 2 步的 AI 私聊已完成。测试服务仍仅在 Tailscale 内网使用测试证书和私有收件箱。尚未更新已安装桌面程序，本轮 Web 与 Ubuntu HTTPS 检查不代替新版桌面、GNOME 或安装包验收；原有暂停项继续保留在[待验收清单](backlog.md)。
