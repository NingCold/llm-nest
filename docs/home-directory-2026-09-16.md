# 用户目录迁移与设置入口（2026-09-16）

## 行为

- 默认数据目录改为用户主目录下的 `.llmn`，桌面安装版的默认配置是其中的 `llmn.toml`。`LLMN_DATA_DIR`、`LLMN_CONFIG` 保持各自的覆盖能力；CLI/TUI 和源码开发的配置选择规则见 [配置文档](configuration.md)。
- 新目录不存在时，持有旧目录的 OS 写锁后，将配置、`.env`、会话 JSON 复制到同级临时目录，复制全部成功才重命名为新目录。旧数据保留；新目录存在时不合并，不重导入。
- 设置 → 关于 → 配置与数据显示后端实际使用的路径，并提供打开目录按钮。IPC 只接受配置/数据两种目标，路径不由前端传入。Web 提示文件位于服务所在机器。
- Windows 使用系统 Shell 打开目录。Linux 使用桌面启动器，并从子进程的搜索路径中排除 AppImage 内的库、GIO/GTK 模块和程序目录，保留宿主桌面环境；返回启动错误或超时。
