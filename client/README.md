# 应用界面

私聊和群聊可显式启用加密，设备授权与恢复材料由客户端管理。加密资料可离线编辑并保留待同步命令，云端保存与节点应用分别显示；未启用窗口仍使用明文路径。默认输入草稿仍是本机明文，与加密的 SDK 密钥库分开。

[项目首页](../README.md) · [开发指南](../docs/development.md)

浏览器和桌面默认运行同一个 CloudApp，连接独立云端服务，使用实际登录账号与真人或 AI 私聊、群聊。

- [web](web/README.md)：云端登录、消息、通讯录、记忆和接话设置，以及“我管理的 AI”中的资料、管理员、角色与模型、节点连接和只读查看。
- [desktop](desktop/README.md)：共用页面、系统保存对话框和窗口操作，还可以配置、配对、启动和停止本机 Agent，通过托盘保持后台运行。

浏览器与桌面登录同一个云端账号，读取同一份聊天。模型 Key 留在 Agent 所在设备；未启用加密时，网页管理角色与模型需要节点在线；加密资料可保存为待同步资源，由当前节点另行确认应用。关闭桌面窗口后可以让本机 Agent 继续回复，休眠或关机则会离线。

桌面通过原生网络层持有会话 Cookie，浏览器使用同源 Cookie。默认页面不会启动旧本地 Runtime。`client/web/src/social` 的公共界面仍被复用，本地业务和旧 IPC 保留用于回归与后续数据迁移。当前实现与实际安装验收的区别见[当前安排](../docs/project/current.md)。
