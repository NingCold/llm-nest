## 本批范围

在已有显式记忆、聊天与来源快照上增加真实窗口摘要。摘要归属 Conversation，当前群成员共享本群分段；不属于某个 AI 的人格或关系记忆。完整原聊天保留，不创建摘要聊天消息、AiRun 或 ParticipationPlan。

- SQLite v8 新增 summary_settings、conversation_summaries、summary_revisions、summary_message_sources，升级前备份，保留 v7 记忆及全部旧数据。未修改历史迁移脚本。
- 成员在聊天/联系人详情选择摘要专用模型、思考强度和输出上限后开启。默认关闭，与 AI 执行绑定及全局参数独立。关闭停止未完成摘要，既有有效分段继续用于上下文。
- 保留最近 12 条 committed 原文，较早未覆盖部分达到 16 条或摘要输入预算时整理下一段；每段最多 32 条，按容量缩小，且不跨过尚未提交的生成消息。手动可提前整理较早部分；单条超预算明确失败，不截断或默默跳过。
- 后台并发 1、每次唤醒最多 4 段、每次请求最长 120 秒。每段持久保存 queued/running/ready/failed/interrupted/stale、attempt、版本、模型绑定、来源、错误和时间。重试沿用分段 ID 与覆盖范围，读取当前原文，失败不自动重试。
- 实际上下文按预算读取 ready 分段，避免重复输入被覆盖的普通历史，当前问题和直接引用仍保留原文。快照只登记实际选中摘要，回答提交再次复核来源。
- 源编辑/撤回同事务清空当前与修订摘要正文并标 stale；配置/窗口参与变化中断未完成任务；迟到结果不能恢复旧正文。关闭和重启将未完成任务保留为 interrupted，不重放外部调用。
- HTTP/SSE 与 IPC/Channel 共用用例和 DTO。详情页可查看范围、来源当前版本、模型、状态、重试、下一段和更早分段；有序缓存读取与持久引用事件共同防止迟到读取覆盖失效状态。

## 与显式记忆的关系

摘要只读取本窗口 committed 原消息，不读取角色内部设定、模型思考、显式记忆、旧摘要或其他窗口。摘要是有损背景，不自动确认事实或产生长期记忆。遗忘显式记忆保留原聊天，因此不删除仅依赖原文的摘要；撤回原消息才使其摘要失效。未来产生依赖记忆的材料时，必须纳入记忆遗忘链路。

当前输入仍采用保守 UTF-8 字节估算；输出上限最多 16384 tokens，正文另外限制为 16384 字节，源集合估算不超过 64 KiB。不宣称精确 token 计数、总费用额度账本、语义检索或永久记住全部历史。模型失败只影响摘要任务，已保存聊天不回滚。超出本次四段上限的积压在后续消息或手动整理时继续处理。
