## 候选扩展

下列按产品方向归并，列举的是可能的范围，进入开发时再确定一个完整目标。首版收尾后的选择取决于实际使用反馈，不按表格顺序自动启动。

| 方向 | 可考虑的能力 | 当前边界 |
| --- | --- | --- |
| 意识与自然交流 | 自动记忆候选、语义召回、后台巩固 / Dreaming、期限与完成状态、自然语言群话题定位、显式转发、语义接话与自然语言结束/约定识别 | M2 / M3 首版已完成；当前使用显式记忆、来源引用、窗口摘要、确定性轮转和明确创建的约定 |
| 文档与图片理解 | TXT/Markdown 预览与模型正文读取，按需要扩展 PDF/Office、图像描述/OCR、视觉能力筛选和动态图播放/编辑 | 普通文件收发/下载/导出已完成，模型只读其元信息；图片能力标识来自目录与人工声明，真实模型识图验收尚未执行 |
| 查找与数据管理 | 语义搜索、附件文件名/正文检索、大文件独立存储、流式 ZIP 与大规模资源验收、草稿跨端同步、独立备份恢复、导出再导入、旧历史接续 | 当前正文搜索、单窗口导出和显式旧历史导入已完成；ZIP 在内存生成，聊天导出不等同整库备份 |
| 更丰富的约定与通知 | 重复日程、每日循环或全局个人免打扰、条件监控、系统唤醒与离线推送 | 当前是一次性约定和窗口内免打扰截止时间，应用退出后不执行主动联系 |
| 账号与多人社交 | 角色复制/模板、初始管理员转让、人工代发、账号视角独立实时订阅、第二个真人账号、远程认证、成员邀请、联网同步和对方已读回执 | 当前为本地一个真人与多个 AI，管理员查看 AI 账号是只读视角；多人联网需单独设计 |
| 明确工具授权 | 具体工具的管理员授权/撤销、已授权白名单工具执行、worker 与协议配对、中断收尾 | 社交执行当前无工具；先有具体使用需求，再确定工具与权限，角色文本和模型输出不能授予权限 |

MCP、任意工具/插件、通用编码代理、知识库和工作流不在当前社交首版范围。旧架构与 README 清理已完成，无需为候选扩展保留旧产品入口。
