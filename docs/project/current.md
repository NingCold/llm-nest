# 当前安排

[已完成](completed.md) · [待验收与候选](backlog.md) · [总计划](cloud-plan.md) · [使用指南](../usage.md)

第 2 步“接入一个 AI 节点”已完成本机 Agent 与云端 Web 的闭环验证。云端 AI 账号、初始管理权、配对码绑定/更换/撤销与状态界面，独立 `llmn-agent`、HTTPS/WSS 连接器、私聊流式回复和停止、持久开始确认及原结果重交已实现。节点支持多个 AI、严格模型校验和每日持久预算；模型 Key 通过节点环境变量引用，角色与执行检查点保存在节点 SQLite。

最新云端容器已部署到内网，保留部署前 PostgreSQL 备份。最终 Agent 二进制已通过远端 HTTPS/WSS 的配对、流式回复、重启不重复调用、取消后继续聊天与撤权检查。Edge 中实际登录、创建 AI 并收到真实文字回复；真实图片经云端授权读取后进入模型，正确识别左右色块。模型 Key 只在节点进程环境，独立节点已在本机后台运行。完整证据与测试边界见[节点验证](../validation/README.md#云端-ai-节点验证)。

下一步按第 3 步接入群聊、显式记忆、每 AI 摘要及参与规则。在线内部配置、管理员授权界面和桌面一键运行/托盘属于第 4 步；现有数据迁移保持第 5 步范围。本批没有更新已安装桌面程序、验证桌面新界面或在 Ubuntu 启动 Agent，不能借用此前平台结果补齐这些检查。

第 1 步“云端真人聊天”及本轮内网验收已完成。邀请注册、邮箱验证、登录与找回密码、联系人和唯一私聊已经实现；消息、图片和普通文件、编辑撤回、已读与置顶、正文搜索和导出也已接通。Web 与桌面共用界面和云端 API。

独立服务已部署到用户提供的测试服务器，只监听 Tailscale 内网地址。使用独立 PostgreSQL、附件目录、测试证书和私有测试收件箱。另一台 Ubuntu 设备已通过 HTTPS 登录、读取历史并回复；服务重启后记录和附件保留。没有迁入现有聊天，也没有替换本机已安装的日常程序。

Windows 独立测试程序已实际登录，与 Ubuntu 互发消息并实时同步，完成搜索、置顶、图片预览、原生文件保存及重启后的历史和草稿恢复。连接按钮现在会检查真实服务响应，修改地址后必须重新连接。完整结果与验证边界见[验证指南](../validation/README.md#云端真人聊天验证)。测试邮箱不向外发信，正式邮件服务和正式证书仍需部署时配置。

第 1 步已补齐原有界面的云端接入：登录后沿用消息/通讯录布局、左下角账号和外观/关于设置。Edge 中已验证真实登录、收发消息、搜索、草稿刷新恢复和浅深主题，详见 [Web 验证结果](../validation/README.md#原有界面接入云端的-web-验证)。尚未更新已安装桌面程序，不以此前桌面联调代替本次界面的桌面验证。
