# 当前安排

[已完成](completed.md) · [待验收与候选](backlog.md) · [总计划](cloud-plan.md) · [使用指南](../usage.md)

第 3 步第三批“接话与约定”已完成并部署到内网测试服务。聊天详情现在可以开启有限自动接话、调整次数、暂停和恢复窗口或单个 AI，以及结束当前交谈。私聊中短时间连续发出的普通消息会一起交给 AI 回答，各条原文仍分别保留。

一次性约定由真人明确创建，群里需先由群主或管理员开启。免打扰可以延后或跳过到期联系，普通聊天仍可回复；过期、取消和结果不明的调用不会自动重做。云端记录发言次数，节点管理模型调用与 token 预算；暂停优先于明确点名，恢复只响应新消息。

群聊、意识系统和接话约定沿用同一套账号、窗口和权限。聊天原文与附件保存在云端；角色、模型配置、显式记忆和各 AI 的窗口摘要仍保存在节点。本机独立 Agent 已配套升级到协议 v4，原账号和资料保留并重新在线。真实数据库、节点、连接器、前端检查及最终部署后的双节点模拟验收通过，详情见[验证记录](../validation/README.md#云端接话与约定验证)，本轮没有调用真实模型。

**下一步是第 4 步：管理与本机运行。** 完善“我的账号 → 我管理的 AI”，接入角色与模型参数的在线管理、管理员名单和只读账号查看；桌面提供“在这台电脑上运行”、关闭后的后台运行和托盘停止。模型 Key 继续只在节点本地填写。完成标准是普通用户可以从界面配置和管理自己的 AI，范围只在[总计划](cloud-plan.md#第-4-步管理与本机运行)维护。

旧数据备份预览与迁移保持第 5 步。本批没有迁移旧库或更新已安装桌面客户端，Web 与节点验收不代替桌面、GNOME 和安装包验收。测试服务仍只在 Tailscale 内网使用；免打扰时间控件的手工验证和其他暂停项见[待验收清单](backlog.md)。
