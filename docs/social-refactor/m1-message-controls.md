日期：2026-10-09。真人消息修订/撤回、单次生成取消、成员/窗口暂停、结束交谈与归档/恢复已接通 SQLite、SocialFeature、HTTP、基础 IPC 命令及真实 Web。所有当前群成员共享本群完整历史；暂停与发言资格不改变群记录可见范围。

## 消息修订与撤回

- 只允许修改或撤回本地真人自己的 committed 消息，按 MessageId + expectedRevision 定位；归档窗口和其他发送者的消息拒绝修改。
- 编辑保存新版本，保持 ID、序号、发送者、回复关系及后续消息。修改不会自动要求 AI 再回答；继续讨论可以发送新消息。
- 撤回保留原位置的 withdrawn 占位，清空正文/附件，并清空旧修订中的内容。旧命令回执只返回实体当前状态，不恢复撤回正文；持久事件始终只有引用。
- 同事务增加来源空间 context_epoch，立即中断依赖该空间的活动运行，保留已落盘片段，并写入 context_changed 执行提示。依赖复核覆盖跨窗口运行；终态写入先完成，随后通知执行任务停止。
- 编辑/撤回触发消息会取消它尚未开始的接话计划；撤回也取消明确回复该来源的待执行计划。其他消息的排队计划继续按最新记录准备上下文。已提交的其他成员消息保留，不批量删除旧回答。

消息版本、事件和命令回执原子提交，重复请求先检查回执，再检查 revision。写入失败不改变历史或发布成功状态。撤回不清理既有备份，也不能撤销供应商已接收的请求；摘要、长期记忆及其来源失效继续在 M2 实现。

## 控制的作用范围

| 操作 | 当前行为 |
| --- | --- |
| 停止这次回复 | 原子取消指定 AiRun 与对应计划，保留已落盘片段；其他计划可以继续，不永久暂停 AI |
| 暂停成员 | 更新该窗口成员的参与版本，取消它的活动回复与等待计划；其他 AI 继续，本群历史仍共享 |
| 暂停全部 AI | 真人仍可保存消息，不创建新回复计划；取消窗口活动运行及排队计划 |
| 恢复接话 | 新消息可以触发新计划，不复活暂停前已取消的计划 |
| 结束当前交谈 | 结束当前 Bout，取消活动回复及排队计划；空间/历史保留，新输入可开始新的交谈 |
| 归档/恢复 | 归档只读并取消窗口运行及队列；恢复沿用原 ConversationId，并保留原暂停设置 |

当前 Bout 在第一个 AI 运行开始时创建；窗口 DTO 返回 currentBout。普通群消息只保存时可以没有活动 Bout。空闲等待、自动结束、连续输入合并和有限自动接话仍归 M3。

## 结构与接口

- `crates/storage/src/social/controls.rs` 负责撤回、依赖运行中断、成员参与控制与结束；已有修订/归档接口改为符合新用例的事务。
- v4 → v5 迁移前备份，为成员加入独立 paused 状态；旧成员默认正常参与。暂停通过成员版本复核，不更改历史范围。
- `features/social/src/controls.rs` 使用短 mutation gate 协调命令、持久收尾与执行取消；HTTP/Tauri 调用同一业务方法和 wire DTO。
- `LiveControls.tsx` 提供编辑/撤回、交谈与成员控制；未知发送结果保留同一 requestId 和 expectedRevision，明确业务错误显示失败。
- 持久消息事件按 MessageId 读取当前版本，已加载的早期消息也能更新。订阅 resync 清除旧页并重新分页；重置前的读取响应不能重新填入旧正文，草稿保留。

本批新增单条消息查询、修订/撤回、窗口控制与成员暂停的 HTTP 和基础 IPC 命令。当前完整路由、字段与命令清单只在 [API 与事件](07-api-and-events.md) 维护；本批未包含实时 IPC 与桌面社交界面。
