# 当前安排

[已完成](completed.md) · [待验收与候选](backlog.md) · [总计划](cloud-plan.md) · [使用指南](../usage.md)

已完成第 3 步第二批“意识系统接入”。在聊天详情和 AI 联系人详情中可以维护显式记忆；每个 AI 分别整理自己的窗口摘要；群里的话题可带到双方已有私聊继续。聊天原文、附件和来源版本由云端保存，记忆与摘要正文保存在节点，私聊记忆不会自动进入群聊。

来源修改、撤回、退群和遗忘会使相关材料失效。节点断线后先补齐来源变化，再继续使用记忆；回复过程中遗忘记忆也会阻止旧回答迟到发布。摘要默认关闭，由有窗口访问权的 AI 管理员选择模型并启用，费用由节点承担。

本批已部署到内网测试服务，部署前保留 PostgreSQL 备份。本机独立 Agent 配套升级到节点协议 v3，沿用原账号、档案与聊天。真实数据库、节点、连接器和前端检查通过；两个实际 Agent 进程连接内网服务，使用模拟模型完成记忆隔离、独立摘要、群话题接续、遗忘和离线来源同步检查，网页操作也已检查。验证范围见[意识系统验证](../validation/README.md#云端意识系统验证)，本轮没有调用真实模型。

**下一批是第 3 步第三批：接话与约定。** 接入有限自动接话、暂停/结束、一次性约定联系、免打扰和额度，完成标准是 AI 能按约定开始、等待和结束交流，重启、退群、屏蔽或停用后不补发旧任务。范围只在[总计划](cloud-plan.md#第-3-步群聊与意识系统)维护，不另拆成不断增加的产品阶段。

完整角色/模型在线管理、管理员名单界面和桌面一键运行/托盘保持第 4 步；旧数据备份预览与迁移保持第 5 步。本批没有迁移旧库或更新已安装桌面客户端，Web 与节点验收不代替桌面、GNOME 和安装包验收。测试服务仍只在 Tailscale 内网使用，其他暂停项见[待验收清单](backlog.md)。
