# 当前安排

[已完成](completed.md) · [待验收与候选](backlog.md) · [同机与加密计划](secure-local-plan.md) · [使用指南](../usage.md)

**第一批“桌面同机文字私聊与断网接续”已实现，并完成自动验证。** 在线登录、启动本机 Agent 并为已有 AI 私聊开启同机连接后，普通文字可以直接交给同机 Agent。断开云端后，当前登录会话仍可继续聊；使用本地模型时不依赖外网模型服务。重新联网只同步已经生成的记录，不重复回答。

同机聊天沿用原账号和私聊窗口，读取节点已有角色、显式记忆和摘要。界面区分本机保存、等待同步、已同步和冲突；刷新后保留发送方式。云端权限、来源或聊天尾部变化时保留本机记录并提示冲突，不自动覆盖或重做。

这批只支持普通文字和最近 64 条缓存显示，不含同机附件、引用、群聊，也不含桌面进程重启后的离线重新登录。当前仍采用原有云端明文存储，**尚未实现端到端加密**。局域网直连已列入待办。

**下一步：第 2 批“私聊、设备恢复与 AI 资料加密”。** 先选定成熟协议和实现，再贯通可信设备、私聊加密、恢复材料，以及角色、模型参数、显式记忆和每 AI 窗口摘要的密文同步。D1–D9、S1–S5 和离线修改、换节点规则见[加密方案](../design/encryption.md)，范围及结束条件集中在[执行计划](secure-local-plan.md)。

本轮云端 42 项真实 PostgreSQL 测试、Agent 37 项单测和 3 项进程集成测试、连接器 13 项测试通过；前端测试、类型检查和生产构建通过。原生桌面编译检查通过，但原生单测程序启动遇到 Windows `0xc0000139`，未实际运行；Linux 同机通道和完整桌面点击操作尚未实测。详见[验证记录](../validation/README.md#同机文字私聊验证)。

新批次尚未部署到内网或替换日常安装版，日常资料未迁移。已部署服务仍是云端第 0–5 步版本；旧库迁移、更换节点及备份恢复的已完成结果见[已完成](completed.md)和[迁移指南](../migration.md)。干净 Windows、GNOME 与正式邮件等原有验收缺口继续保留。
