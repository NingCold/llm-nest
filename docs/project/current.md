# 当前安排

[已完成](completed.md) · [待验收与候选](backlog.md) · [总计划](cloud-plan.md) · [使用指南](../usage.md)

当前在第 1 步“云端真人聊天”的验收收尾。邀请注册、邮箱验证、登录与找回密码、联系人和唯一私聊已经实现；消息、图片和普通文件、编辑撤回、已读与置顶、正文搜索和导出也已接通。Web 与桌面共用界面和云端 API。

独立服务已部署到用户提供的测试服务器，只监听 Tailscale 内网地址。使用独立 PostgreSQL、附件目录、测试证书和私有测试收件箱。另一台 Ubuntu 设备已通过 HTTPS 登录、读取历史并回复；服务重启后记录和附件保留。没有迁入现有聊天，也没有替换本机已安装的日常程序。

目前正在确认 Windows 桌面实际连接和聊天界面；测试结果与未完成项统一记录在[验证指南](../validation/README.md#云端真人聊天验证)。测试邮箱不向外发信，正式邮件服务和正式证书仍需部署时配置。

下一批是第 2 步“接入一个 AI 节点”：创建云端 AI 账号、由管理员授权节点、通过连接器完成私聊回复，并验证断线和撤销后的行为。模型 Key 留在节点；群聊、意识系统及现有数据迁移按总计划后续步骤推进。

Linux 桌面新布局、干净 Windows 安装等原有平台验收继续暂缓，见[待验收清单](backlog.md)。本轮服务器和 Ubuntu HTTPS 客户端测试不代替 GNOME 桌面验收。
