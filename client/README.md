# 应用界面

[项目首页](../README.md) · [开发指南](../docs/development.md)

LLM Nest 提供浏览器和桌面两种使用方式，它们使用同一套页面。

- [web](web/README.md)：消息、通讯录、聊天详情、账号管理和设置。调整页面时，从这里开始。
- [desktop](desktop/README.md)：把页面装进桌面窗口，并负责应用启动、窗口操作和安装包。

两种方式使用相同的聊天功能。你可以先在浏览器里修改和调试页面，再到桌面应用检查窗口体验。

客户端代码与服务端、Agent、连接器分开维护。桌面目前通过 IPC 使用内嵌的本地运行时，独立云端服务、Agent 进程及节点网络连接仍待接通。
