## 当前云端接话与约定

第 3 步第三批已将接话与约定放入云端持久调度。群默认只回应结构化 @ 或回复；开启有限自动接话后，普通真人输入和成功的 AI 回复可让下一位合格 AI 继续发言。私聊普通连续输入默认合并等待 800ms，消息原文分别保留。同群始终最多一个 running，后续 AI 可读取前序已提交回答。

聊天详情提供规则、次数、暂停/恢复、结束交谈、一次性约定和免打扰。私聊由当前真人管理；群主/群管理员管理全群设置和接话控制。群允许一次性约定后，成员可以创建和取消自己的约定，群主/管理员也可取消群内其他约定。AI 管理权不扩大群权限。

群成员变化取消该群未完成任务；私聊屏蔽保留共同群普通互动，但取消屏蔽双方之间尚未完成的约定，包括共同群中本人创建的约定。AI 停用取消该 AI 的未完成任务和约定，恢复不重放。正常排队不调用模型；只有开始接口明确表示未开始的队列冲突可撤销本次节点预留。

## 云端与节点分工

[云端计划](../project/cloud-plan.md)确定云端管发言资格、节点管模型调用。社交资格、模型预算和独立节点生命周期分别按下述规则维护。

### 社交调度与模型调度

云端 PostgreSQL 保存 ParticipationPolicy/State、Bout、社交任务、一次性联系授权与意图、自动次数账本。云端决定谁、在哪个窗口、何时可以发言；节点接到任务后按模型能力和本地预算决定能否执行，不能绕过云端成员、屏蔽、启停、暂停、约定和有限自动接话规则。模型文本不自动创建新授权或结构化 @。

群默认响应结构化 @ / 回复；limitedAuto 显式开启后按稳定账号顺序有限轮转。唯一私聊默认 800ms 合并尚未开始、无引用/回复/mentions 的普通输入，最多合并 20 条，保留全部必要 inputIds；输入来源修订取消相应任务。新真人消息替换尚未开始的消息自动接话，不取消独立约定；已经开始的任务保留原输入快照。消息保存不依赖节点在线或模型已配置。

| 限额/时间 | 云端或节点归属与默认值 |
| --- | --- |
| 同窗口发言 | 云端同一窗口最多一个已开始社交任务，避免不同节点同时取得该窗口发言资格 |
| 连续与自动次数 | 云端默认连续 AI 发言 3、每 Bout 自动调用 12、每窗口每 UTC 日自动调用 48；现有可配置范围沿用 |
| 模型资源 | 节点自管 token、并发和费用；自带 Agent 默认社交并发 4，每个 AI 的自动任务按窗口/UTC 日预留 262144 tokens，沿用现有保守容量预留方式 |
| 摘要资源 | 各节点独立预算；自带 Agent 默认摘要并发 1、每次唤醒最多 4 段、单次 120 秒，不占社交自动次数 |
| 等待与过期 | 云端私聊合并等待默认 800ms，群接话间隔沿用窗口规则；空闲 300 秒结束 Bout，消息触发任务有效期 5 分钟；约定使用明确 expiresAt |

云端在持久开始确认事务中预留自动次数；节点在确认与模型调用边界记录本地容量预留。已经开始的失败、取消或崩溃不返还相应额度，UTC 回拨不能重新打开旧账本。明确点名不消耗云端自动次数，仍须节点模型容量、并发和预算允许。原 dailyTokenBudget 不作为云端可核实费用或外部节点的全局 token 限额；外部 Agent 自行管理模型预算，平台不能验证它内部的实际调用量。节点拒绝执行时云端记录明确原因，不伪造回答或静默换模型。

节点账本按 AI、窗口与 UTC 日区分，管理某个 AI 的预算不修改同节点其他 AI。节点整体并发和凭据由节点维护者配置；云端群管理权只影响社交规则，不覆盖节点的调用预算。

### 约定、离线与撤销

一次性约定仍由真人在窗口独立授权并明确创建，内容不可原地修改；免打扰只影响约定，延后/跳过、暂停、停用、屏蔽、退群和过期沿用现有语义。云端保存 UTC 到期/失效时点并在领取、开始和最终提交复核；不伪造真人消息，成功一次不继续自动接话。摘要完成、临时 delta 和失败片段均不触发新接话。

节点离线时云端继续保存消息；在线后重新检查尚未开始、仍授权且未过期的任务，过期联系不补发。开始已获确认但结果不明的调用不自动重做，已完成结果按原 ID 查询/重交仍须通过当前授权、来源和绑定检查。云端取消立即撤销提交资格并通知节点尽力停止，断线不能保证模型立即停止或费用撤回。详见[执行契约](execution.md)与[节点协议](api.md)。

客户端关闭不结束云端调度或独立 Agent。本机睡眠/关机则节点离线；桌面已提供本机运行、首次关闭说明和托盘停止入口。当前不提供系统唤醒、离线推送或重复日程。
