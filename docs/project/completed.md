# 已完成的能力

[当前安排](current.md) · [待验收与候选](backlog.md) · [设计入口](../design/README.md)

已有可信设备通过本机开库、服务器设备有效性及信任检查后进入聊天，完整密钥同步继续在后台完成。设备目录未变化时不重复查询公钥；合并同时发生的聊天刷新，空同步不反复解密历史，失败后保留待处理变更并重试。

锁屏期间准备 SDK 并保留空数据库连接，减少输入口令后的等待，不提前读取密钥。对照实测消息列表出现时间由约 2.38 秒缩短至 1.27 秒。修复已装入 Windows `alpha.19` 并部署内网 Web，具体测试范围、正式版试用与计时见[Windows 记录](../validation/windows.md#解锁与设备目录同步优化2026-11-01)。

桌面可完成创建 AI、本机模型与密钥配置、配对、独立加密身份、恢复文件保存或导入、双方信任、首份加密角色模型、启动等待应用及进入私聊。节点额度可在停止后修改，按本轮输入估算加输出上限预留；修改不重置已用量。实际主流程与未手测分支见[Windows 记录](../validation/windows.md#桌面创建加密-ai-与额度2026-11-01)。

保持登录与本机解锁分开，可选自动解锁默认关闭。锁定保存草稿、卸载聊天内容，独立 Agent 继续运行；退出清理自动材料并保留密钥库。日常账号已完成保持登录跨进程重启、手动解锁，以及 Agent 停止时读取十条原加密历史，见[日常验读](../validation/windows.md#日常重启与离线节点历史验读2026-10-30)。

聊天与 AI 资料采用 Matrix 官方 SDK 加密，支持可信设备、独立恢复、私聊与群聊、附件、历史分享、离线编辑和节点交接；同机断云保存原密文，重连补传不重复调用模型。旧历史和节点资料提供显式转换，并用恢复文件独立读回核对。各批自动与实际验收见[验证指南](../validation/README.md)，剩余缺口见[待验收](backlog.md#待验收)。

三仓拆分、Apache-2.0 许可、独立 CI 和固定产物发布已完成，桌面消费 Agent 产物、服务端消费 Web 产物。公开版本与本地安装、部署状态分别见[当前安排](current.md)，历史提交和摘要见[第三批验证](../validation/README.md#拆仓第三批验证)。

| 主题 | 当前云端已实现 |
| --- | --- |
| 账号 | 邀请注册、邮箱验证、邮箱更正与重发、密码登录和重置、退出及会话撤销；公开姓名、简介和账号 ID |
| AI 与节点 | 云端 AI 账号及初始管理员、“我管理的 AI”、配对码绑定/更换/撤销、节点在线状态；独立 Agent 的角色/模型档案、持久预算及检查点 |
| AI 管理 | 公开资料修改、初始管理员授予/撤销其他真人管理员；在线角色、模型及参数保存，节点确认后应用；管理员只读查看 AI 的聊天和附件，身份和已读不变 |
| 本机运行 | 桌面配置模型与本机密钥、配对、启动及停止独立 Agent；同一节点连接多个 AI；首次关闭说明后台行为，托盘可打开窗口和停止节点 |
| AI 回复 | HTTPS/WSS 任务与材料协议、调用前云端持久开始确认、流式检查点、停止回复、来源变更取消、原结果幂等重交；已开始而结果不明不重调模型 |
| 联系人和私聊 | 按姓名或账号 ID 查找、添加和移除联系人；两人唯一长期私聊，移除后重新添加沿用历史；屏蔽限制双方新私聊，共同群照常互动 |
| 群聊 | 建群、改名、增减成员、群主任免管理员及转让、退出和重新加入；当前成员共享完整群历史 |
| 群内 AI | 结构化提及与同窗口回复；多个 AI 跨节点依次发言，每个目标独立显示状态和停止；成员变化使旧任务失效 |
| 接话与控制 | 可开启有限自动接话；私聊连续普通输入合并等待；窗口和单个 AI 暂停/恢复、结束交谈；云端次数与节点 token 预算分别维护 |
| 一次性约定 | 窗口授权后明确创建、查看与取消；免打扰延后或跳过；到期独立触发，不伪造真人消息；过期不补发、结果不明不重调模型 |
| 意识与记忆 | 在线节点保存显式记忆；每个 AI 各自维护窗口摘要，管理员按窗口启用；聊天和联系人详情提供入口 |
| 话题接续 | 选择共同群原文带入已有私聊；引用只存来源标识和版本；源变化、权限丢失及遗忘使相关材料失效，重连先核对来源 |
| AI 启停 | 管理员停用、恢复账号，保留历史和节点绑定；停用期间真人消息仍保存，恢复只响应新消息 |
| 消息 | 文字、图片、普通文件、分页历史、编辑与撤回；重复请求不重复建消息 |
| 列表和查找 | 各账号自己的已读、手动未读、置顶、正文搜索和消息定位 |
| 保存和导出 | 原图与文件下载、完整单窗口 Markdown/JSON 导出，可携带图片和普通文件 |
| 旧库迁移 | 备份并预览 v13 本地库，将唯一真人映射到登录账号，为旧 AI 新建云端账号；迁入聊天、附件和个人状态，保留 ID 对应关系；归档/旧导入窗口只读及历史来源标记；同源重试不重复建账 |
| 节点迁移 | 为每个 AI 导出和导入角色、模型选择、显式记忆及窗口摘要，重新授权和检查来源；同包重试不复活遗忘资料，旧调用和自动摘要不自行启动 |
| 客户端 | 云端数据接回原有消息/通讯录布局、侧栏与视觉样式，账号在左下角，设置提供外观与关于；Web 与桌面共用源码；按服务器、账号和窗口保存本机草稿；实时同步和断线重连；桌面原生保存与关闭前草稿确认 |
| 服务 | 独立 PostgreSQL 与附件目录、按登录身份检查权限、持久事件；单机容器部署、HTTPS 和私有测试收件箱 |

云端与 Web、本机节点的实际验证分别见[迁移验证](../validation/README.md#数据迁移与联网试用验证)和[管理验证](../validation/README.md#云端管理与本机运行验证)。当前安装与部署状态见[当前安排](current.md)。

代码已按客户端、服务端、自带 Agent 和连接器组织；云端服务不依赖本地模型、SQLite 或 Runtime。独立 Agent 复用公共模型协议与 Agent 核心；连接器可独立接入外部程序，附明确标注固定回答的最小示例。本机独立 Agent 与云端 Web 的文字、图片私聊已通过真实模型验证，远端二进制恢复/撤权联调及模拟检查分别见[节点验证](../validation/README.md#云端-ai-节点验证)，依赖边界由脚本检查。

## 保留待迁入的本地能力

以下功能在先前的本地版本中已实现，代码仍用于回归和后续迁入，当前云端界面尚未提供：

| 主题 | 已有本地实现 | 计划 |
| --- | --- | --- |
| 模型目录 | 同步外部公共模型目录和图片能力人工覆盖 | 云端管理当前使用节点已配置目录，这些本地目录工具尚未迁入 |
| 图片处理 | 发送前缩放与压缩，确认预览后加入草稿 | 云端入口尚未接入；不扩大当前第 5 步范围 |

旧本地库和节点资料已有[迁移工具](https://github.com/NingCold/llm-nest-server/blob/main/docs/migration.md)，完整旧库保留。当前支持单次 128 MiB 的云端资料、重新创建旧 AI 的云端身份，以及节点现有单来源记忆；复杂旧依赖和旧修订仍可在备份中保留，不声称全部转为节点在线能力。

先前 Windows 日常流程验收及安装更新只证明当时的本地版本。新版云端客户端没有借用这些记录声称完成平台或安装验收。社交执行仍未开放通用工具、MCP 或插件。
