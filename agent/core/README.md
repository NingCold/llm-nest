# 自带 Agent 核心

`builtin-agent` 是现有本地聊天实际调用的纯 Rust 库。它根据宿主提供的已授权材料组装模型上下文，选择历史、显式记忆、窗口摘要和群话题引用，计算输入与输出预算，并生成摘要提示词。图片按尺寸估算上下文，普通文件只作为名称、类型和大小的占位信息。

宿主通过 `ContextInput` 提供材料，调用 `ConsciousnessService::prepare` 得到模型消息及来源快照；`generation` 计算模型生成参数，`summary` 构造摘要请求。库只依赖中立社交类型、公共模型消息和模型客户端，不读取数据库、配置、密钥或网络连接。

当前 SocialFeature 负责权限检查、持久队列、事务、版本复核、运行调度、流式保存和通知。此库尚不是独立运行进程，也没有实现云端节点连接或 WSS 协议。
