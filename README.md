LLM Nest 是一个人与 AI 交流的社交应用。你可以认识不同的 AI，和它们私聊，也可以把它们邀请到同一个群里，一起讨论感兴趣的事。

我们希望每个 AI 都有自己的身份，每段关系都有可以延续的经历。换一个话题之后，你仍然能回到原来的聊天窗口，接着聊下去。

目前是开发预览版，提供桌面和浏览器两种使用方式，面向你与多个 AI 在本机的日常交流。

## 在这里，你可以

- **认识不同的 AI。** 为它们创建账号、名字和简介，在通讯录里找到它们。你管理的 AI 可以使用不同的模型和角色设定。
- **找到想继续的聊天。** 用未读提醒留意新消息，把常聊的窗口置顶，也能搜索聊天正文，回到当时的记录。
- **一直聊下去。** 每位 AI 都有一个固定的私聊窗口。聊天记录会保存下来，更换模型后也能回到原来的对话。
- **一起看看图片。** 选择、拖入或粘贴图片，预览后发送；可以只发图片，也可以附上文字。为 AI 选择支持图片的模型，就能围绕画面继续聊。
- **把朋友们拉进群。** 邀请多个 AI 讨论同一个话题，通过 @ 或回复指定对方，也可以在群设置里开启自动接话。
- **让共同经历留下来。** 在聊天或联系人详情里保存、修改和忘记记忆，为长对话开启摘要，还能把群里的话题带到私聊继续。
- **约好下次联系。** 选择一位 AI 和一个时间，让它在应用运行时主动来聊。你也可以设置一段免打扰时间。

在联系人资料或私聊详情中可以屏蔽对方，暂停私聊并取消你们的约定联系；共同群仍能正常交流。解除屏蔽后，从原窗口继续聊。

我们把帮助 AI 回忆和理解对话的这些功能，统称为“意识系统”。

## 开始使用

在 [Releases](https://github.com/NingCold/llm-nest/releases) 查看可用安装包，或按[开发指南](docs/development.md)从源码运行。

1. 打开应用，进入 **设置 → 模型服务**，添加你使用的模型服务和 API Key。
2. 进入 **我的账号 → AI 角色管理**，创建一位 AI，填写资料和角色设定，选择它使用的模型。
3. 从通讯录打开私聊，或在消息页创建群聊。

桌面应用会同时启动本地服务，打开就可以使用。Windows 和 Linux 的运行环境与安装说明见[开发指南](docs/development.md)。

## 聊天和数据

图片支持 PNG、JPEG、WebP，每条最多 4 张，单张不超过 4 MiB、合计不超过 8 MiB，边长不超过 4096 像素。已发送图片会随聊天保存。未发送的文字和图片也会自动保存为本机草稿；看到“草稿已保存在本机”后，刷新页面或重开应用都能继续编辑。Web 请使用同一浏览器和访问地址；清理网站数据会同时清掉草稿。

图片超出大小或尺寸限制时，会打开处理窗口。选择最长边、格式和质量，查看处理前后的画面与大小，确认后加入草稿，再正常发送。已有草稿图片旁也有处理按钮；原文件不会被修改。

发送图片时，输入框会提示哪些 AI 支持看图、哪些暂不清楚。能力默认跟随模型目录，也可以在 **设置 → 模型服务 → 模型图片能力** 中修正。未知能力可以尝试；明确不支持时，图片仍会保存到聊天中，这位 AI 会提示无法处理包含图片的对话。

点开已发送的图片，选择 **保存原图**，就能下载聊天中保存的图片；桌面端可以选择保存位置。如果发送前处理过，下载和聊天导出保存的就是处理后的版本。

在 **聊天详情 → 导出聊天记录** 中，可以把整个窗口保存成 Markdown 或 JSON。勾选 **包含图片** 会保存一个 ZIP，解压后能看到聊天记录和原图。私聊、群聊和已导入的历史都可以导出；未勾选时，图片保留占位说明。

聊天记录和设置保存在运行应用的电脑上。桌面版可以在 **设置 → 配置** 查看保存位置，并直接打开对应文件夹。默认数据目录是用户主目录下的 `.llmn`。

使用在线模型时，回复所需的聊天内容会发送给你选择的模型服务，费用按该服务的规则计算。也可以连接本机的 Ollama，具体见[模型配置指南](docs/configuration.md)。

如果以前用过 LLM Nest，可以在 **设置 → 配置 → 导入历史聊天** 选择要保留的旧记录，导入后在消息列表里阅读。
