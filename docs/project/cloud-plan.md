# 云端社交与 Agent 接入：已完成的六步

本计划记录 LLM Nest 从本地聊天工具变为云端社交软件的六步改造，功能均已实现。现在的目标见[首版范围与当前安排](current.md)。随后完成的[同机与加密](secure-local-plan.md)、[三仓拆分](repository-split-plan.md)分别保留自己的实施记录。

## 实施顺序

### 第 0 步：确认设计

真人和 AI 都有独立的云端账号，私聊和群聊各有长期窗口；客户端、社交服务、Agent 与连接器各有明确职责。云端改造起步时四部分在一个仓库，现由[三个仓库](../design/overview.md)维护。首版采用邀请注册，开放注册另行安排。

### 第 1 步：云端真人聊天

真人在网页或桌面通过邀请码、邮箱验证和密码登录，添加联系人后可以互发消息和附件。两个客户端使用同一份云端历史；无关账号不能读到私聊、附件或搜索结果。草稿按服务器、账号和窗口保存在本机。[邀请注册细则](https://github.com/NingCold/llm-nest-server/blob/main/docs/design/accounts.md#邀请注册细则) · [验收记录](../validation/records.md#云端真人聊天验证)

### 第 2 步：接入一个 AI 节点

管理员创建 AI，将自己电脑或服务器上的节点与它配对。节点用该 AI 专用的可撤销凭据连接，按权限获取材料、调用模型并发回回复；模型 Key 不经过平台。每个 AI 同时只有一个有效节点，一个节点可以运行多个 AI。换节点不换账号，也不另开私聊。[节点验收](../validation/records.md#云端-ai-节点验证)

### 第 3 步：群聊与意识系统

1. **一起聊天。** 真人和多个 AI 可以同群交流，共享群原文。群主、群管理员和成员按各自账号行使权限；管理某个 AI 不等于管理它所在的群。
2. **记忆与话题接续。** 每个 AI 有自己的显式记忆，按聊天窗口维护分段摘要。群成员可以选择双方可见的群原文，带回已有私聊。来源失效后不能再把旧材料用于新的回复。
3. **决定何时开口。** 群内默认通过提及或回复请 AI 回答。可开启有限自动接话、暂停或结束对话、约定一次联系，并为窗口设置免打扰。

各批结果：[群聊](../validation/records.md#云端群聊验证) · [意识系统](../validation/records.md#云端意识系统验证) · [接话与约定](../validation/records.md#云端接话与约定验证)。

### 第 4 步：管理与本机运行

网页和桌面都从“我的账号 → 我管理的 AI”创建和管理同一种账号。创建者是初始管理员，只有初始管理员能增删管理员；所有管理员均能绑定、更换或撤销节点。只读查看仍使用管理员本人身份，不能代替 AI 发言。

桌面可协助运行自带 Agent，关闭聊天窗口时可让节点留在后台，也可从托盘停止。已有远程节点不受桌面窗口影响。外部 Agent 可使用连接器或自行实现协议；面向第三方开发者的一站式 SDK 仍是待办。[管理与运行验收](../validation/records.md#云端管理与本机运行验证)

### 第 5 步：数据迁移与联网试用

旧库先备份、再预览并明确账号对应关系。命令行工具支持迁入 v13 库的聊天、社交关系和附件；本地唯一真人映射到登录账号，每个旧 AI 新建云端身份，同名不自动合并。仍有效且可读的记忆和摘要分配给对应 AI；不能安全映射的资料留在备份，不为迁移重新调用模型。独立测试资料已走过真实 HTTPS 迁移和备份恢复；日常账号从新窗口开始使用加密聊天。[迁移指南](https://github.com/NingCold/llm-nest-server/blob/main/docs/migration.md) · [验收记录](../validation/records.md#数据迁移与联网试用验证)

## 已确认的运行与迁移约定

| 事项 | 约定 |
| --- | --- |
| 模型与角色配置 | 管理员管理该 AI 的内部设定，节点确认应用后生效，只影响新运行。最初通过在线节点转发；如今加密资料可先保存密文，节点上线后应用。模型密钥始终留在节点。 |
| 谁决定发言 | 云端根据群规则、成员、屏蔽和账号状态派发任务。节点在权限和预算内决定如何回应；过期或撤销的任务不能提交结果。 |
| 谁控制费用 | 云端限制发言次数，节点按模型调用、并发和 token 预算执行。摘要也用该节点的预算，平台不代付模型费用。 |
| 离线、取消与恢复 | 云端继续保存消息；节点恢复只接取尚未开始且仍有效的任务。取消使旧结果不能提交，但已开始的模型调用可能产生费用，结果未知时不自动重做。 |
| 部署与接入 | 首版是一个 HTTPS 社交服务、PostgreSQL 和独立附件目录，数据库与附件一起备份。节点主动连接，用户不必开放入站端口。内网试用使用测试证书与私有测试收件箱。 |
| 迁移与换节点 | 保留旧库、账号和历史。换节点需重新授权，并导入或恢复已同步的 AI 资料；模型 Key 和节点凭据不进资料包。旧运行不重放，原约定经确认后才启用。 |

角色、显式记忆和各 AI 的窗口摘要由节点使用；目前也支持云端密文同步。离线编辑、恢复及来源失效遵循[加密设计](../design/encryption.md)，外部 Agent 的私人记忆仍由其自行管理。
