# 正在推进的工作

当前开发里程碑为 **M2：意识系统完善**，业务线为“记忆、摘要与跨窗口接续”。第一批 [显式记忆](m2-explicit-memory.md)、第二批 [窗口分段摘要](m2-window-summaries.md) 已完成。第二批贯通 SQLite v8、专用模型与独立任务、上下文读取、来源失效、Web/IPC 与详情界面，规则见 [意识系统](03-consciousness.md)。

**下一批是 M2 第三批：群聊话题接续唯一私聊**。先实现群消息选择和可查看/移除的引用草稿，再让私聊发送保存 ContextReference、请求按共同群权限读取必要片段，最后贯通源编辑/撤回/退群的失效与提交复核。继续沿用原唯一私聊，私聊内容不自动回传源群。自动候选、后台巩固与全局语义召回不作为这一批的前置。

M1 第 4 条业务线仍有平台收尾未完成。已完成的异常/打包、NSIS 本机重装、桌面启动及连续拖动分别见 [阶段验收](m1-stage-validation.md)、[本机重装](../windows-reinstall-2026-10-09.md)、[启动外观](m1-desktop-surface.md) 与 [拖动](m1-desktop-drag.md)，这些历史证据不扩展为本批意识系统的安装验收。

**安装验收继续暂缓**：按用户 2026-10-10 的要求，不执行干净 Windows 的 NSIS / MSI 首次安装、缺少 WebView2、卸载重装及窗口检查；Linux 新内容内窗口控制仍待 GNOME 实机复验。本批未重打安装包、未覆盖个人已安装程序、未访问个人聊天库，不阻塞已安排的 M2 开发。

工具授权在有具体需求时另行实施，当前社交执行无工具。M3 的自动参与/约定联系、多人联网、初始管理员转让和后台记忆巩固均未接入。完整剩余清单见 [尚未完成](pending.md)。
