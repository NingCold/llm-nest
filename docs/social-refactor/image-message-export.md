# 图片消息第二批：原图保存与携图导出

2026-10-13。[当前进度](in-progress.md) · [消息](02-conversations-and-messages.md) · [接口](07-api-and-events.md) · [第一批记录](image-messages.md)

## 使用方式

点开聊天中的图片，选择“保存原图”。浏览器开始下载，桌面打开系统“另存为”。图片不重新编码，保存的字节与消息中保留的原图一致。普通聊天、搜索定位、群来源预览和管理员只读账号视角共用该入口；待发送图片没有这一按钮。

在聊天详情中选择 Markdown 或 JSON，再勾选“包含图片 · 保存为 ZIP”，即可一起保存完整窗口记录与原图。未勾选时仍下载原有文本文件，图片只保留占位说明。按钮在准备文件期间禁用；失败保留选择并允许重试，桌面取消单独提示。Web 显示“已开始下载”，桌面写入成功后才显示“已保存”。

## 文件结构

ZIP 的建议文件名为 `LLM-Nest-{窗口名}-{窗口ID}.zip`，包含一种所选格式的记录：

```text
chat.md 或 chat.json
images/
  {消息ID}-{part索引}.png
  {消息ID}-{part索引}.jpg
  {消息ID}-{part索引}.webp
```

图片文件名由稳定消息 ID、当前 body part 索引和识别的格式生成，不使用客户端文件名、账号名字或外部路径。相同消息中的多张图分别保存，不重新压缩；ZIP 使用 Stored 写入，解压工具无需特殊支持。Markdown 使用相对图片链接，在支持图片的阅读器中打开解压后的 `chat.md` 即可显示。JSON 的 `format` 仍为 `llm-nest.conversation`，携图包内 `version: 2`，图片 part 增加 `filePath`；普通文本 JSON 保持 `version: 1`。JSON 不内嵌 base64 或字节数组。空窗口也能导出，只含记录文件。

仅附当前窗口当前版本的图片；已撤回的图片不附带，历史修订和引用来源群的图片不展开。其他文件附件仍为占位。记忆、摘要、思考、角色内部设定及凭据不导出。遇到无法识别的旧图片类型会明确报错，不生成缺图后却声称成功的 ZIP。导出文件不是整库备份，不接入旧历史导入器。

## 读取与保存

`SocialStore::conversation_transcript` 的 `include_images` 决定是否在同一只读事务保留原图。消息正文、图片字节和 revision 来自同一份快照，不在事务结束后逐图重新读取拼接；实际操作者需为当前成员，管理员身份不扩大聊天导出范围。该读取不改变已读、事件或运行。数据库无需迁移，仍为 v13。

`SocialFeature::export_conversation_archive` 在事务结束后用 blocking 任务构建 ZIP，HTTP 与 IPC 共用格式化。HTTP 直接传二进制，带 UTF-8 文件名、消息数、no-store 与 nosniff；无需把整个包转成 base64。实现使用 [zip 的 ZipWriter](https://docs.rs/zip/9.0.2/zip/write/struct.ZipWriter.html)。当前在内存生成完整包，尚未做超长多图窗口的流式输出与资源压力验收。

原图保存经 `SocialFeature::image_file` 重新读取，不复用已加载预览：普通范围复核操作者成员身份；账号视角复核管理员和目标账号成员身份。revision 不符、消息撤回、索引无图或权限撤销均拒绝。桌面在显示保存对话框前检查一次，用户选定路径后再次读取和复核；路径只来自原生对话框，不接受任意客户端路径或 operatorId。

原图、文本导出与 ZIP 共用同目录临时文件写入、同步、替换流程；写入或替换失败保留既有目标并清理临时文件。取消不写文件，失败不报告成功。用户已保存的文件不会被之后的消息撤回自动改写。

## 验证与剩余项

- Windows MSVC：storage、social-feature、web-server、tauri-frontend 共 121 项测试通过；包括快照版本与原图对应、文字修订保图、撤回移除、成员权限、ZIP 相对路径、两种记录格式、原图字节一致、错误图片、二进制替换保存及失败清理。格式检查与 Clippy 完成，保留既有风格提示。
- Web：类型检查、13 组脚本和生产构建通过。覆盖 Web 原图/ZIP 二进制下载、Unicode 文件名、权限失败不下载、临时链接清理、原图按钮重复点击/失败重试/取消、携图选项与 IPC 参数映射。
- HTTP：图片专项与完整社交回归通过，覆盖原图下载、管理员只读范围、修订/撤回/退群后拒绝旧读取、Markdown/JSON ZIP、引用不展开、空窗口及约 5.6 MiB 双图原始数据。旧文本导出的 207 条完整历史和宿主/显式导入/worker 回归也通过。全部使用隔离数据和本地模拟模型。
- 浏览器实际选图发送、从预览保存原图、从详情下载携图 ZIP，并读取落地文件核对原图与包内图片的 SHA-256 一致。界面截图保存在忽略目录 `target/image-original-save-web.png`、`target/image-export-web.png`。
