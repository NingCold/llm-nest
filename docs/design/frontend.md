# 界面与桌面

[设计总纲](overview.md) · [接口](api.md) · [运行与配置](runtime.md)

Web 与 Tauri 默认共用云端真人与 AI 私聊、群聊界面。当前进度见[当前工作](../project/current.md)，环境与实测范围见[验证入口](../validation/README.md)。

## 默认云端页面

`client/web/src/App.tsx` 默认加载 `cloud/App.tsx`。Web 与 Tauri 共用 CloudApp，提供邀请注册、邮箱验证、登录/找回密码、公开资料与登录会话管理、通讯录和真人私聊。按名字或完整账号 ID 查找联系人；同一对账号总是打开同一个私聊。“我的账号 → 我管理的 AI”已提供云端 AI 创建、配对/更换/撤销和节点状态；群创建/成员与角色管理、提及/回复、多 AI 任务、联系人屏蔽和 AI 启停已接入；节点记忆、各 AI 私有摘要与群话题接续也已接入；有限自动接话、暂停/结束和一次性约定已接入；角色/模型在线配置与桌面一键运行/托盘仍待后续接入。

界面持续沿用原有设计：消息与通讯录是两个主入口，自己的账号位于左下角，设置提供外观与关于。`cloud/App.tsx` 管理认证、云端状态、订阅与草稿，`cloud/AuthPage.tsx` 提供登录等认证页面，`cloud/Workspace.tsx` 接入登录后的界面，并复用 `social/components/SocialSidebar`、公共组件与 `social.css`。更换数据来源不另起一套聊天布局，也不加载旧本地业务。此次界面接入先验证 Web，尚未更新已安装桌面程序；此前桌面联调只代表当时版本。

消息页支持文字、PNG/JPEG/WebP、普通文件、自己的消息编辑/撤回、未读与手动未读、置顶、正文搜索及原消息前后定位。图片预览与附件读取始终使用当前消息 revision；修订后丢弃旧加载结果，撤回不显示旧正文或附件。导出从服务端读取完整聊天窗口，附件可选；浏览器下载 Blob，桌面通过系统保存对话框写入原字节。

Web 使用同源 fetch/EventSource；Tauri 使用 `cloud_request`、`cloud_subscribe`、`cloud_unsubscribe`、`cloud_save_download` 和 Channel 转发同一云端 API。原生层仅保存内存 Cookie，退出/重启后需重新登录；服务器地址保存在本机。切换账号或服务器会失效旧请求和订阅。测试 CA 仅通过启动环境 `CLOUD_CA_CERT_FILE` 指定，不关闭证书校验。

桌面启动或点击连接时实际读取 `/me`：未登录的 401 表示服务已连通，可以继续登录；网络、证书及其他 HTTP 错误保持未连接并显示原因。地址交给原生层校验通过后，统一保存 origin 作为草稿命名空间。输入地址发生变化时停止使用原连接登录，连接过程中显示进度，不将“地址已保存”当成连接成功。

持久 `change` 事件触发重新读取权威快照与相关聊天；只有读取并应用成功才推进游标，断线用最新游标重连。正文搜索和上下文定位不自动确认已读；正常聊天只有前台聚焦、页面可见且滚动到底部时才确认同快照的已读位置。身份来自当前会话，不切换全局操作者读取其他账号。

草稿复用 `social/draft-storage.ts`，以服务器/实际账号/窗口隔离，文字、结构化提及、回复目标和附件 Blob 与发送命令原子保存。未知结果保留原 requestId 手动重试，不自动发送，成功清理原快照并保留期间新输入。关闭窗口先等待附件读取与草稿写入；失败保留窗口。默认页面不调用旧本地初始化，不启动 Runtime；窗口操作不依赖云端登录成功。关闭窗口不停止远端服务，当前尚无托盘本机 Agent。

## 已确认的云端创建与管理方向

云端创建与配对已接入 `cloud/AiManagement.tsx`，当前实现初始管理员、公开名字/简介创建、节点状态与授权、AI 停用/恢复、打开私聊。Agent 从独立 CLI 初始化、配对和运行；网页和桌面采用同一配对码，绑定/替换/撤销保留原 requestId 重试。聊天触发消息显示排队/运行/失败状态，停止按钮调用任务取消；生成片段从服务端快照刷新。以下完整内部管理、只读视角和桌面后台入口仍是目标。官网与桌面创建同一种云端 AI 账号，桌面后续可选择本机自带 Agent。创建不切换真人登录身份，创建者成为初始管理员。

主导航继续使用“消息 / 通讯录”，通讯录可并列真人与 AI，公开资料使用同一结构。AI 管理统一放在“我的账号 → 我管理的 AI”，涵盖自己获授权管理、从官网或桌面创建、在本机或服务器运行的 AI。管理权与联系人关系独立，创建后不强制添加联系人。

创建完成进入该 AI 的管理页，提供“与它聊天”（打开唯一私聊）、“管理 AI”（内部设定、模型、节点）和“查看它的账号”。查看时明确显示被查看的 AI 与实际管理员，采用只读视角，不提供人工代发。节点采用单个有效节点、管理员手动更换。

窗口关闭行为已确认：关闭桌面窗口默认让本机 Agent 继续后台运行；首次关闭时说明并提供停止选项，托盘中也可随时停止。远程节点独立运行，不受本窗口关闭影响；本机休眠或关机时，本机运行的 AI 离线。本机 Agent 作为独立进程运行，聊天窗口关闭不终止它；这些行为属于已确认目标，现有关闭流程见后文。

管理页区分云端公开资料与节点内部资料。模型选择、生成参数、角色设定、显式记忆和各 AI 的窗口摘要通过云端复核授权后转发在线节点；节点保存成功才显示成功，普通配置只用于新运行。节点离线时内部资料不可远程读写，不排队提交；超时显示“结果未确认”，沿用同一 requestId 查询或重试。模型 Key 只在节点本地填写，网页不提供 Key 输入。界面按节点实际支持的能力展示管理项，外部 Agent 不必具备自带 Agent 的所有编辑能力，语义见[API 设计](api.md)。

聊天和联系人详情提供对应窗口的显式记忆入口，云端按成员与来源范围授权后转发节点。管理员在有窗口访问权时，还可打开所选 AI 的私有摘要与专用模型设置；普通成员没有这个入口。摘要不再是群成员共用的资料，完整 AI 内部配置仍归“我的账号 → 我管理的 AI”。

`cloud/Participation.tsx` 在聊天详情显示接话规则、连续发言和自动次数，提供窗口/AI 暂停、恢复、结束，以及一次性约定与免打扰。群主/管理员维护全群设置，成员可在授权开启后创建和取消自己的约定；未确认命令在本次登录内保留原 ID 与内容重试，设置草稿不被 SSE 刷新覆盖。

`cloud/Consciousness.tsx` 管理在线记忆和摘要；节点离线、读取失败和空列表分开显示。未知保存结果在本次登录的内存中按服务器/账号/AI/窗口保留原命令，可原样重试，或读取当前资料后明确结束原操作；不把记忆正文写进持久客户端草稿。`cloud/References.tsx` 提供群原文选择与预览，确认后将来源 ID/版本加入已有唯一私聊草稿，保留文字和附件，不自动发送。草稿与待确认发送快照一同保存引用元数据，发送与预览再次检查来源。

网页与桌面的聊天统一经云端 HTTPS/SSE，实际操作者由服务端认证；桌面 IPC 仅用于系统交互和本机节点管理。草稿按服务器、实际真人账号和窗口隔离，切换服务器或账号不能串用。客户端断网时保留草稿；节点离线时云端仍可保存消息，界面分别显示客户端断网、节点离线、AI 停用，以及消息已保存和执行失败，不能将保存消息等同于 AI 已开始执行。

节点恢复只处理尚未开始且仍有效的任务，过期不补发；已开始但结果不明的调用不自动重试。取消后的旧结果由云端拒收，界面不承诺已经发出的模型调用立即停止或免除费用。运行和迁移的完整范围见[已确认约定](../project/cloud-plan.md#已确认的运行与迁移约定)。

## 本地社交界面参考（待迁移）

以下章节记录 `src/social` 的本地业务与 IPC 约定，供回归及迁移参考；其中侧栏、基础组件和视觉样式已由云端页面复用。默认 CloudApp 已接通真人登录、AI 创建/节点配对及私聊；下文的完整 AI 管理、群、意识、模型设置及旧本地运行控制仍是保留实现。

### 信息结构

主导航只有“消息”和“通讯录”两个入口。消息页显示持续私聊与独立群聊，通讯录显示稳定 AI 联系人；设置通过独立按钮进入，记忆管理嵌入聊天详情和联系人详情。首版不增加记忆主导航、公开广场或推荐信息流。

意识系统（Consciousness）是统一后台机制。详情页继续使用“记忆”“历史摘要”“引用来源”等具体标签，帮助用户理解操作；系统命名不增加“意识”主导航，也不将后台任务状态显示成角色清醒或睡眠状态。

| 区域 | 默认展示 | 详情与操作 |
| --- | --- | --- |
| 消息列表 | 名字/群名、头像、最后完整消息、未读与置顶 | 暂停标记、归档、搜索 |
| 私聊顶部 | 对方身份、参与状态 | 档案、共同记忆、主动联系设置 |
| 群聊顶部 | 群名、成员 | 成员管理、参与模式、群记忆 |
| 通讯录/联系人详情 | AI 与真人一致的账号资料、唯一私聊入口 | 联系关系、相处设置与有范围的关系记忆 |
| 自己账号下的 AI 角色管理 | 所获授权的 AI 账号 | 内部设定、执行配置、停用/恢复、登录账号查看；初始管理员可授予其他管理员；不是第三个主入口 |
| 消息正文 | 发送者、时间、回复对象、正文或附件 | 编辑修订、撤回、再次回应、来源、与某 AI 私聊继续 |
| 运行详情 | 可折叠的执行状态 | 用量、计时、思考、错误 |

AI 与真人账号详情采用同样的内容与界面结构，公开资料与 AI 内部设定分开。模型选择、reasoning effort、temperature、内部角色设定在管理员自己的 AI 角色管理页面维护；工具授权尚未接入，普通联系人详情不提供这些专有字段或编辑入口。当前共同字段为名字、类型、状态、公开简介、账号 ID 和 avatarRef；头像上传尚未接入，界面使用名字头像。更换模型后的行为差异通过管理空间的配置变更提示表达，不声称人格必然完全一致。

初始管理员可从管理页面授予其他账号管理员权限。每个获授权 AI 提供登录账号查看的入口，进入该 AI 自身权限范围内的账号视角，明确当前被查看账号与实际管理员，并能返回自己的账号。首版入口用于查看，不提供人工代发消息；账号切换不取消 AI 自动执行。当前账号视角是带权限检查的快照与分页历史，手动刷新；没有为这个视角复用实际操作者的全局订阅。

关系级移除只撤下当前用户通讯录中的条目，历史与共同群互动保留；未屏蔽时允许继续私聊，重新添加沿用原 ConversationId 并保留屏蔽状态。联系人资料和私聊详情提供屏蔽/解除：首次屏蔽确认影响，保存失败保留操作；屏蔽私聊显示提示并保留草稿，解除后继续输入。共同群正常交流，约定表单排除已屏蔽对象。规则见[身份与关系](accounts.md)。全局停用/恢复在管理员的角色管理页面操作，保留数据，恢复只响应新消息。

### 路由与组件落点

主入口路由为 `#/messages` 和 `#/contacts`。聊天使用 `#/messages/{conversationId}`，聊天详情及记忆使用 `#/messages/{conversationId}/details` 与其 `/memories` 子页；联系人详情使用 `#/contacts/{actorId}`，关系记忆位于其 `/memories` 子页。自己的资料位于 `#/account`，角色管理使用 `#/ai-management` 与 `#/ai-management/{actorId}`，只读账号视角使用 `#/account-view/{actorId}`；均通过自己的账号进入，不增加主导航。现有 `#/settings/models|appearance|config|about` 保留。`#/chat` 按未知入口落到消息列表；未知或无权访问的 ID 显示可恢复状态。

点击同一联系人始终打开同一个私聊 ConversationId；群列表每项打开对应独立群窗口。结束当前交谈、更换模型或切换话题不清空记录，也不新增联系人私聊。

打开归档窗口保持只读，提供显式恢复操作；恢复使用原 ID，并在保存成功后允许发送，不自动重放归档前的队列。

真实群消息已提供“私聊继续”：选择当前共同 AI 成员、1–8 条附近已加载原文与可选相关摘要，预览校验成功后打开唯一私聊，加入可查看/移除的引用草稿。保留已有文字、回复和 @ 选择；替换引用会重置发送请求 ID，单纯导航不发送。引用草稿只持久化 ID/版本，不保存群正文；发送失败保留输入与同一重试 ID。来源卡每次按当前游标重新读取，断线/失效不显示旧预览，迟到读取不覆盖新状态。失效引用需回到群聊重新选择；自然语言定位与显式转发尚未实现。实现见 [验证入口](../validation/README.md)。

组件按领域拆分为 contacts、conversations、messages、consciousness、participation 与 settings。consciousness 包含 MemoryPanel、SummaryPanel 和引用来源展示，仍嵌入两种详情。界面复用基础 UI、Markdown、代码与 Mermaid 渲染。

输入草稿按 conversationId 保存；档案和设置表单按对象保存。切换页面不会停止运行、清空输入或重复建立订阅。隐藏聊天 Header 时卸载菜单 portal，避免覆盖其他页面。

### 视觉与布局

共用 React 界面参考 Codex 的连续表面与紧凑侧栏，采用中性灰白 / 炭黑底色与克制的蓝色强调，继续使用已有 Tailwind、Radix 和 Lucide；社交语义样式集中在 `social.css`，设置通过同一组变量衔接。无需增加动效库、远程字体或图片依赖。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 主背景 / 侧栏与面板 | `#ffffff` / `#f6f6f6` | `#181818` / `#202020` |
| 正文 / 辅助文字 | `#242424` / `#747474` | `#ededed` / `#a0a0a0` |
| 边框 / 链接与焦点强调 | `#e8e8e8` / `#3573c4` | `#303030` / `#8cb8ed` |
| 主操作按钮 | `#242424` 配白字 | `#ededed` 配炭黑字 |

聊天正文与输入为 15px，表单与联系人名称为 14px，列表摘要和按钮为 13px，时间及辅助说明为 12px，AI 标签为 11px。桌面将主导航、列表与自己的账号合为 288px 侧栏，“消息 / 通讯录”横向切换；聊天顶栏 72px，消息与输入区限制在 800px 居中。真实聊天的 AI 正文去掉外框，自己的消息为柔和灰色气泡，输入区为低阴影圆角表面；Markdown 表格和代码在自身区域横向滚动。

大窗口的详情占独立一栏，1050px 以下为覆盖面板，700px 以下为全宽详情。850px 以下采用列表 / 内容切换；700px 以下在列表和账号页使用底部导航，进入聊天后隐藏底部导航，用聊天顶栏返回。设置在手机宽度下改为顶部横向分类。浏览器视口检查不代替手机软键盘实机验收。

公开账号资料使用紧凑身份区及简介、ID、关系区，不使用大封面；真人与 AI 仍共用资料结构。管理页使用横向账号选择、身份与操作区、内部设定 / 执行配置、管理员 / 运行状态；宽窗口两列，窄窗口一列。长名称在选择器中截断，在详情中换行，选中账号保持可见。普通资料不展示执行参数。

搜索框聚焦使用外层中性细边与轻背景，避免输入内部叠加外框；其他按钮与输入保留可见键盘焦点。消息列表显示当前窗口的未发送草稿。生成状态标注具体发送者，停止按钮明确当前 AI 回复，继续发送仍可用。弹窗保留 Radix 的键盘行为，关闭后回到触发按钮；主导航与当前列表项有 `aria-current`。颜色过渡为 160ms，详情进入为 180ms，桌面首次界面淡入为 220ms；减少动态效果偏好会关闭动画与过渡。

### 状态管理

| Store | 负责内容 |
| --- | --- |
| actorStore | 档案、执行可用状态与联系人列表 |
| conversationStore | 会话列表元数据、成员、当前空间与已读位置；不保存生成的历史摘要 |
| messageStore | 分页消息、临时发送记录与修订 |
| runStore | 按 RunId 管理生成片段、活动与终态 |
| live-store 中的记忆状态 | 按窗口/AI 顺序读取记忆、按窗口顺序读取摘要；分页与事件刷新串行，读取成功后推进订阅游标；引用选择随私聊草稿保存，来源预览按游标重读；自动候选确认留待后续 |
| participationStore | 暂停、成员模式、交谈与联系意图 |
| connectionStore | 订阅生命周期、cursor、重连与补齐状态 |

上表描述状态职责，不强制拆成七个 store；当前真实实现集中于 live-store.ts，按实际复杂度拆分。AI 生成不通过全局 isStreaming 阻塞输入。输入是否可发送取决于当前空间访问、历史加载、附件状态和存储连接；AI 生成状态单独管理。

真实社交已允许先保存真人消息，再判断 AI 是否可执行。无模型时给出“消息已保存，该 AI 需要配置”的明确状态。

### 发送、流式与重连

当前发送保存草稿、requestId 和 sending 状态；成功回执合入服务器消息，失败保留输入与重试 ID，不预建持久真人或 AI 消息。未来如加入乐观发送气泡，其 sending/failed_to_send 仅是传输状态，不能伪装成后端消息。

真人消息保存成功不预建 AI 消息。后端 run_changed/message_changed 引用到达后读取运行与消息建立生成展示，标明谁正在输入、回应哪条消息。生成期间用户可继续输入和发送。

消息持久状态与传输状态分开。SocialMessage 的 committed/generating/interrupted/withdrawn 与 AiRun 的 cancelled/failed 分别表达，不能与发送失败混用；最终记录覆盖临时缓冲。新消息未读以完整可见消息为准，自身消息不增加未读。

订阅在应用级维护一个实例，页面读取共享 store。持久事件按 ID 去重并按 cursor 顺序应用；状态获取失败先重试或重新快照，不提前推进 cursor。终态后不接受旧 delta。

重连时显示连接与补齐状态，先恢复服务器权威记录和活动运行；不继续拼接断线前无法核对的 token，也不把断线展示为 AI 主动结束聊天。

### 三种停止操作

- “停止这次回复”：cancelRun，只中断选定运行。
- “暂停 AI 参与”：pauseMember 或 pauseConversation，停止后续自动回应；真人仍可记录消息。
- “结束本次聊天”：endBout，保留关系与空间，取消本 Bout 接话队列并中断其活动运行；独立未来约定保留。

这些操作在按钮、菜单和状态文本中明确区分。暂停后的恢复是显式动作；约定联系是否继续在详情中可见，关闭主动联系会取消相应意图。

### 消息列表与搜索

消息列表提供全部/未读筛选，数字提示新到消息、蓝点提示手动未读；每行菜单可置顶/取消置顶和标为已读/未读。状态保存在本地服务中，Web 与桌面重开后沿用。置顶优先，同组按最新完成的消息排序。当前聊天手动标未读会返回列表，等再次打开最新聊天时再确认。

自动已读要求页面可见、窗口有焦点、当前为正常聊天且滚动在底部，最新历史读取成功后等待 500ms 确认。翻看历史、定位搜索结果、切到账号/设置或失焦时不确认；确认失败显示错误，保存成功才刷新状态。成功的自动已读与后台历史、运行、计划读取保留发送后的执行提示；用户可以关闭提示或通过下一次操作清除。主导航也显示未读提示。

“搜索聊天和正文”保留按名字/群成员过滤，同时查询全部保存的正文；打开聊天时可以把正文范围改为当前聊天。搜索延迟 250ms，每页 50 条，可继续加载与失败重试；新查询、范围或来源变化丢弃迟到读取。选中结果进入原窗口的 `#/messages/{conversationId}/at/{messageId}`，高亮原消息并显示前后记录；“返回最新消息”恢复普通聊天和已读确认。群消息上的“私聊继续”从当前显示页选择来源，搜索定位的较早消息也可接续到唯一私聊。记录没有被复制进另一个窗口或浏览器持久缓存。

### 普通文件消息

“添加文件”提供独立选择入口，草稿显示文件名、大小和移除按钮，支持纯文件发送。每条最多 4 个、单个 10 MiB、合计 20 MiB；图片保留原有入口与处理限制。拖放/粘贴按浏览器类型分配到图片或文件；明确通过文件入口选择图片时也作为普通文件。输入区说明 AI 当前只看到名称、类型和大小，尚未读取内容。

MessageFiles 在聊天、搜索定位、群来源预览和管理员只读账号视角显示元信息与“保存文件”。Web 下载 Blob；Tauri 打开原生另存为，取消、保存和失败分别反馈。普通文件不内联预览。编辑已发送消息可以清空正文并保留文件。草稿文件共用附件 Blob 事务、待确认发送重试和桌面关闭等待，旧图片草稿继续恢复。实现见[聊天与消息](conversations.md)。

### 图片消息

输入区在草稿有图片、群引用或回复图片时显示支持/不支持/未知。私聊显示对方，群聊有结构化 @ 或回复 AI 时显示目标，否则显示当前所有 AI 成员；不改变群接话规则，不禁用真人发送。普通聊天只消费账号能力标识，不接触内部模型绑定。历史图片和群引用是否进入本次请求，由后端意识系统及 AiClient 统一检查；明确不支持时显示执行原因，其他群成员仍能回复，详见[运行与配置](runtime.md)。

输入框可选择、拖入或粘贴 PNG/JPEG/WebP，预览、移除后发送，允许纯图片。每条最多 4 张，单张 4 MiB、合计 8 MiB，边长 4096。超出尺寸或大小时打开“发送前处理图片”；已有草稿缩略图旁也有主动处理按钮。可以选择最长边 4096/2560/1600/1024、WebP/JPEG/PNG 和有损质量 90%/80%/65%，默认 2560、WebP、80%。图片按比例缩小，不放大小图；PNG/WebP 保留透明，JPEG 用明确白底。

原图与处理预览并排显示，可点开放大，并显示各自尺寸、文件大小和全部图片总量。生成预览不发送、不保存为草稿；选项变化清除旧预览，仍超限则不能确认。确认时才加入或替换目标窗口的图片草稿，保留文字/回复等输入；取消与迟到结果均不修改草稿。处理结果为静态图片且不保留拍摄信息，原文件不改写。待处理源单张最多 20 MiB、解码后最多 6400 万像素；超出时提示先在其他图片编辑器缩小。

历史图片进入可见范围时读取，失败提供重试，点击放大使用共用 Radix 对话框。已发送图片的预览提供“保存原图”，保存时重新读取当前权限与版本，不使用预览缓存；待发送草稿不显示这一按钮。处理后发送的图片，下载和导出均使用处理后的字节，不保留可回取的处理前副本。撤回、修订和引用失效切换会卸载旧图；迟到读取不覆盖新版。普通聊天、搜索定位、群来源预览和管理员只读账号视角使用同一图片展示，账号视角经专用权限读取。消息列表和纯图片回复引用显示“[图片]”。

Web 与 Tauri 共用 File 输入；桌面 dragDropEnabled=false 使 WebView 接收文件拖放，不增加任意路径读取。平台实测范围见[验证入口](../validation/README.md)。

### 本机未发送草稿

未发送草稿将文字、图片、文件与提及/回复/群话题引用一起保存在 IndexedDB，刷新或重开同一浏览器地址/桌面应用后恢复。按实际真人账号与窗口隔离，恢复完成后才能编辑；保存中、保存成功、保存失败及重试入口直接显示在输入区。多个页面修改同一草稿时提示冲突，不覆盖另一页的内容。

发送前先持久保存原内容与 requestId；结果未知时保留独立快照，重开后可查看原内容、手动重试或放弃重试，不自动发出消息。放弃不撤回可能已送达的消息。成功回执清理对应附件和原草稿，保留等待期间新增的内容。Web 在还有未完成附件读取/写入、保存错误或未确认的图片处理时，通过 beforeunload 提示；桌面关闭流程见下文。草稿只在当前浏览器或桌面 WebView 保存，不属于服务器历史、跨端同步或整库备份，清理网站/应用浏览数据会删除草稿。实现与验证见[存储与迁移](storage.md)。

### 聊天导出

聊天详情的“聊天”页提供“导出聊天记录”，默认 Markdown，可切换 JSON；“包含图片”和“包含文件”默认均关闭，可分别选择，任一开启后保存为 ZIP，内含所选格式的记录与附件。私聊、群聊、归档及已导入历史均显示该入口；不依赖前端已加载记录。导出期间禁用操作，失败保留所选格式与两项附件选择并允许重试，切换窗口重置提示。Web 显示“已开始下载”，桌面在文件写入完成后显示“已保存”，取消单独提示。未选类型的附件占位和不附带记忆/思考/内部设定的范围在入口说明。

导出组件为 `ConversationExportPanel`；单个附件保存使用 `ImageSaveButton` / `FileSaveButton`。客户端 `exportConversation` / `saveImage` / `saveFile` 根据宿主使用 HTTP 文件下载或 IPC 原生另存为；业务读取与格式化共用 SocialFeature。桌面不向 WebView 开放通用文件写入或 dialog 插件命令权限。详见[聊天与消息](conversations.md)。

### 桌面窗口与关闭

共用 `social/App.tsx` 和 `live-store.ts`，`client.ts` 按 IS_DESKTOP 选择 HTTP 或 Tauri 适配器。桌面通过 invoke 发送业务命令、通过 Channel 接收共用订阅；初始化失败显示真实错误，不切换到 HTTP 或模拟回答。切换设置/通讯录/聊天不停止 AI；页面重载释放旧订阅，重新读取快照与已保存历史。

桌面后端内嵌于应用，通过 IPC 自动初始化，无需另开 Web Server。Windows 首次绘制先露出空白原生 Acrylic；React 模块与本地服务初始化期间保持空白启动层，成功或报错后才显现界面。失败保留实际错误、重试和设置入口，不能停留在空白层。Web 使用可读的加载提示。

Windows/Linux 关闭系统标题栏，社交页不再预留独立 56px 顶栏。窗口按钮嵌在内容右上角，相关内容头部留出按钮宽度；社交/设置侧栏空白、聊天与账号等页面头部支持原生拖动及双击最大化/还原，未选中聊天时的空页面自身空白也可拖动。交互元素与搜索框不拖动，聊天正文和账号正文保留文字选择；不使用覆盖内容的顶部拖动层。按钮、关闭收尾和错误提示独立于业务初始化。Linux 使用主题底色的空白启动层，当前改动尚未在 GNOME 实机复验，不声称已实现 Windows 原生磨砂玻璃。关闭主窗口先通过 `drafts-prepare-close` 让已注册页面停止编辑、完成正在读取的附件和草稿事务；尚有未确认图片处理时先要求确认或取消；10 秒未确认关闭或保存失败时保持窗口及后端可用并提示重试。收到当前页面/关闭请求的成功确认后，再等待 Runtime 中断运行、保存片段并关闭 SQLite writer；该阶段 20 秒超时或保存失败时保持窗口打开并提示再次关闭。

### 记忆、摘要与约定详情

私聊详情与联系人详情访问同一份关系记忆，群详情管理本群记忆。面板显示内容、类型、范围、来源、状态和时间，支持手动添加、编辑、遗忘，以及从一条消息明确“记住”。来源变化后显示 stale，需要重新核对或改为手动条目。遗忘移除记忆及其使用，原聊天由撤回控制。

历史摘要面板按窗口显示分段、覆盖范围和任务状态，提供独立模型/预算设置、整理下一段与失败或失效重建。默认关闭；开启前说明独立调用费用。摘要事件触发有序重读，失败不沿用旧缓存、不推进订阅游标，迟到任务或来源读取不能恢复失效正文。

接话规则显示私聊等待、空闲结束、群有限自动接话，以及连续、Bout、UTC 日次数和保守 token 预留上限。版本冲突保留表单，未知结果沿用原请求 ID 重试。约定联系单独授权，默认关闭；日期按本机时区输入，保存 UTC 与固定偏移，拒绝夏令时跳过的无效时刻。免打扰选择一次截止时间及延后/跳过，只影响约定。面板展示全部活动意图与最近 50 条记录，取消使用意图版本；应用退出后不执行或唤醒系统。

### 设置与平台边界

设置路由为 `#/settings/models|appearance|config|about`。模型服务提供图片能力三态与来源、跟随目录或人工覆盖；成功保存才更新状态。该声明不等于真实识图验收。AI 生成参数来自角色管理中的 ExecutionBinding，普通资料不返回内部设定；管理员只读账号视角不提供记忆代编辑。

配置页显示后端启动时冻结的实际路径，并提供所选旧 JSON 的检查与显式导入。源变化需重新检查，成功重复提交不产生重复窗口，原文件保留。历史和设置失败保留错误与重试，不能让窗口控制失效。打开目录 IPC 只接受 config/data 枚举，Web 无此服务器目录功能。

`IS_DESKTOP` 选择桌面 IPC；`CUSTOM_WINDOW_CHROME` 选择 Windows/Linux 内容内窗口按钮与拖动区域，Linux 仍走 IPC。当前本地版本关闭主窗口会关闭 Runtime 并退出进程，尚无托盘或后台常驻；最小化时 Runtime 继续工作。上文确认的后台运行属于后续云端改造目标。

Windows 保留透明 WebView 合成表面与 shadow=false。启动 HTML 透明，初始化成功或失败后界面不透明；原生底色用 Window.setBackgroundColor 同步。普通 Windows 11 窗口由 DWM 绘制圆角/边框；未最大化或全屏、上下占满当前显示器 rcWork（容差 2 物理像素）时关闭原生描边并画 1 物理像素矩形内描边。状态事件带 revision，迟到事件不覆盖新状态。Windows 10 不支持 DWM 属性时回退细边框。窗口不使用透明外边距、额外阴影窗口、区域裁切或 CSS 裁切整个应用。Linux 使用主题底色，不具有 Windows Acrylic 声明；其新布局仍按[候选清单](../project/backlog.md)安排实机复验。

桌面前端输出到忽略的 `client/desktop/dist`，Web 为 `client/web/dist`，验收构建可用 `.social-runtime-dist`。生成权限 schema 不手改，权限源是 capabilities。公共和 Windows 配置均使用 dragDropEnabled=false。图标唯一源为 `assets/branding/app-icon.svg`，安装 identifier、路径与升级标识按[发布指南](../releases.md)保持。

验证使用同一真实界面、独立临时数据和模拟 provider；详见[验证入口](../validation/README.md)。
