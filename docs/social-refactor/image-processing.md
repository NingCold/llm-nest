# 图片消息第四批：发送前缩放与压缩

2026-10-13。[当前进度](in-progress.md) · [界面说明](08-frontend-and-desktop.md) · [草稿记录](image-drafts.md)

## 使用方式

合规图片仍按原文件加入草稿。选图、拖入或粘贴后，如果单张大小、尺寸或加上已有草稿后的总大小超限，会打开“发送前处理图片”。已有草稿缩略图旁的处理按钮也可以主动打开该窗口。

选择最长边、输出格式与质量，点击“生成处理预览”，对比原图和结果的画面、尺寸与文件大小；两边都可点开放大。确认后才加入草稿或替换当前图片，再由用户正常发送。修改选项会清除旧预览，需要重新生成并确认；结果仍超限时不能确认，可以继续缩小或调整格式/质量。取消保留原草稿。

| 选项 | 当前行为 |
| --- | --- |
| 最长边 | 4096 / 2560 / 1600 / 1024 像素，默认 2560；等比例缩小，不放大小图 |
| WebP | 默认格式，有损压缩，保留透明 |
| JPEG | 有损压缩，透明区域明确合成为白色背景 |
| PNG | 无损编码、保留透明；缩小尺寸仍会改变像素，质量选项禁用 |
| 压缩质量 | 90% / 80% / 65%，默认 80%；实际文件大小以预览结果为准 |

处理生成静态图片，照片方向按浏览器解码结果绘制，拍摄信息不保留。原文件不修改，输出文件名附“处理后”和对应扩展名。消息保存、模型输入、图片另存为和聊天携图导出均使用用户确认的结果，不保留可回取的处理前文件。未处理的合规图片继续保留原字节。

## 处理与草稿边界

`image-processing.ts` 在共用前端完成检查、等比例计算和 Canvas 编码，无新增依赖、HTTP/IPC 图片处理接口或数据库迁移。服务端仍检查真实格式与原有限制：每条最多 4 张、单张 4 MiB、合计 8 MiB、边长 4096。待处理源限定 PNG/JPEG/WebP，单张 20 MiB，解码后最多 6400 万像素；这不是浏览器解码器的硬内存配额。超限或无法解码时保留已有草稿并显示错误。

编码使用 [Canvas toBlob](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/toBlob)。浏览器可能在不支持指定格式时回退 PNG，因此实现核对输出 MIME；遇到不支持或编码失败显示错误，允许重新选择格式，不伪报转换成功。临时图片 URL 和画布在完成、失败或取消后释放；取消后迟到结果丢弃。

`ImageProcessingDialog` 位于应用层，绑定开始选择时的窗口。临时源文件和处理预览仅留在内存，确认前不写进 IndexedDB，不产生聊天记录或 AI 请求。Web 请求离开提示，桌面关闭检查要求先确认或取消；已有持久草稿保持不变。原生关闭消息仍沿用第三批的协调协议。

确认时重新检查当前窗口的图片数量、总大小和被替换图片；成功读取结果后生成新的图片 ID，保留文字、提及、回复及群话题引用，并沿用第三批的草稿保存事务。存储失败仍保留已确认结果供重试。正在等待发送回执的快照不随草稿处理改变；旧成功回执不能清掉处理后新图片。如果回执在处理结果读取期间清除了待替换图片，确认会提示原图片已移除，不恢复已发送内容。刷新只恢复已经确认并保存的草稿，不自动发送。

## 验证

- 前端类型检查、15 组测试脚本和 `build:social-runtime` 生产构建通过。新脚本覆盖等比例/不放大、格式和文件名、透明与 JPEG 白底绘制、编码失败/格式回退、URL/画布清理、未确认不入库、不自动发送、取消与迟到处理、当前草稿总量、替换与待确认命令隔离、确认后存储失败重试、关闭等待和旧预览失效。
- 真实 Web 配合隔离 SQLite 与本地模拟 provider：6000 × 3000 的透明 PNG 处理成 2560 × 1280 WebP，预览约 86 KiB → 22 KiB；确认加入草稿、刷新恢复及发送通过。
- 从消息接口读取实际落盘文件验证：WebP 为 21666 字节，透明/半透明区域保留；JPEG 为 31920 字节，背景为白色；带 EXIF 方向的 1200 × 600 JPEG 处理成 600 × 1200 PNG（19174 字节），上下色块方向正确，没有放大且不带原拍摄 EXIF。
- 多图合计边界：3 张各约 2.87 MiB 的 PNG 触发总量处理；PNG 重编码后合计约 9.85 MiB，确认禁用；改为 WebP 后旧预览失效，重新生成约 1.95 MiB，可确认。取消未改变原草稿或创建消息。浏览器控制台未见警告或错误。
- 截图 `target/image-processing-web.png`、构建日志与临时图片均保存在忽略目录；文档链接和当前接口表同步检查。

Rust 业务、协议和桌面原生命令未修改，本批不将此前的 Rust 测试数量重新计为本批验证。构建保留既有大 bundle/动态导入提示。未使用个人配置或付费模型，未更新本机安装程序；Windows/Linux WebView 实际编码、系统选图/剪贴板、处理期间关闭仍待平台复验，浏览器验收不代替这些项目。
