# 待验收与候选

下一批的目标是[让受邀者独立开始聊天](current.md)。这里保留两类事项：已有功能还缺哪些使用证据，以及哪些功能留到以后再考虑。

## 待验收

| 场景 | 还要确认什么 |
| --- | --- |
| 邀请与日常使用 | 新人能否凭界面和说明完成注册、设备恢复、首次私聊和群聊；AI 管理员能否独立完成节点配对。扩大邀请前落实站点证书和真实邮件送达。 |
| 登录、锁屏与恢复 | 30 天登录、自动解锁分别到期；暂停跨重启、退出清理及离线重启的实际表现。已有日常账号保持登录、手动解锁和历史验读记录；自动解锁尚未在该账号开启。 |
| 节点与 AI 资料 | AI 恢复文件导入的桌面操作、实际节点交接和离线编辑；暂忙后的刷新，以及全网断开并使用本地模型、进程重启后的接续。已有同机断云补传验证。 |
| 桌面与安装 | Windows 干净系统首次安装、缺少 WebView2、MSI 实装及卸载重装暂缓；其他缩放比例、未测页面拖动和新版 Linux GNOME 输入、附件、窗口及同机通道等有设备再验。见[Windows 安装清单](../packaging/windows-clean-install.md)和[Linux 记录](../validation/linux.md)。 |
| 故障与安全 | WebView 草稿写入失败、读写附件时关闭的实机检查仍待补；内网快捷方式曾报告无法打开，尚未复现。公开稳定版本前仍需独立安全审查。 |

解锁等待已有[正常运行时的基线](../validation/windows.md#解锁与设备目录同步优化2026-11-01)。如日常使用出现回退，再检查设备校验和首列表请求。

## 未排期候选

- **接入更多 Agent。** 已有连接器和协议示例。第三方 SDK 的目标是让外部 Agent 不下载服务端源码，就能完成配对、领取任务和加密收发。
- **扩展设备与联网方式。** 局域网直连、浏览器完整离线运行、离线重新登录和离线群聊尚未提供。
- **让对话更连贯。** 自动记忆、语义召回、后台巩固和自然语言约定属于后续探索。首版先用显式记忆、窗口摘要和有来源的群话题引用。
- **处理更多材料。** 发送前图片缩放压缩、外部模型目录同步与图片能力人工覆盖是旧本地版能力，当前云端界面尚未接入。普通文件目前只给模型名称、类型和大小；正文提取、OCR 和文档理解另行规划。
- **按反馈再选。** 更丰富的搜索与导出、跨端草稿、重复日程与推送、管理员转让等尚未排期。通用工具执行、插件、MCP 和知识库不属于首版。
