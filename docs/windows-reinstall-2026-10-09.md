# Windows 本机卸载重装验收（2026-10-09）

本批在已有 WebView2 的 Windows 11 开发机，对当前用户安装的 **NSIS 版**实际执行卸载和重装，通过程序移除、原路径恢复、数据保留、开始菜单启动与历史读取检查。结束时应用已正常关闭，重装后的程序保留供继续使用。

使用 [上一批最终候选包](social-refactor/m1-stage-validation.md#本地产物和证据)，没有重建程序或修改运行时代码。源码基线为 `2b90814`；工作区已有的模型目录修改未纳入本批。

## 实际过程与结果

1. 确认应用未运行。将个人 `.llmn`、已有 GUI 数据、安装文件及独立合成历史复制到用户主目录的 `.llmn-backups/reinstall-*`，逐文件校验备份和原文件的 SHA-256。备份留在本机，未提交或上传。
2. 执行原安装目录的 `uninstall.exe /S`，退出码为 0。程序目录、卸载登记及原有开始菜单快捷方式全部移除。个人配置、GUI 数据和合成历史的文件哈希与 SQLite 各表数据指纹保持一致。
3. 执行最终 NSIS 包的 `/S /D=<原目录>`，退出码为 0。普通卸载和重装均未使用 `/UPDATE`，也未选择删除用户数据。登记、程序和快捷方式恢复；安装 EXE 与卸载前相同，数据校验再次通过。
4. 运行 `scripts/windows_package_acceptance.py`，核对重装 EXE 与构建产物，除预期的 Tauri 三字节包类型标记外完全一致；清空继承环境后，固定 `add` worker 返回 5，`shell` 被白名单拒绝。MSI 行政解包的相同比对也通过，该检查不代表 MSI 实际安装过。
5. 从恢复的开始菜单快捷方式启动安装版，子进程使用独立配置、数据目录和全新的测试 WebView 缓存，没有依赖开发服务器。界面正常读到三个 AI 联系人、原唯一私聊与独立群窗口；私聊显示原真人消息、AI 中断片段及中断提示，群详情显示真人和三个 AI 共四位成员。
6. 点击正常关闭并确认进程退出，再次核对持久文件和 SQLite 全部表的数据指纹。个人配置、原 GUI 数据及合成库正文未变，`integrity_check` 为 `ok`；退出仅移除了 SQLite 临时 WAL/SHM 文件，没有删除历史或重放原运行。

## 数据证据的边界

默认 `.llmn` 当时只有一份个人配置，没有真实社交历史；本批证明该配置和原 GUI 数据被保留。联系人、执行绑定、管理员关系、私聊、群成员与消息的保留，通过之前已存在的隔离合成库验证，没有将测试账号写入个人目录。

合成库有 4 个账号、3 份 AI 档案与执行绑定、2 个聊天窗口、6 条成员关系和 2 条私聊消息（真人原文与中断 AI 片段）；群当时没有消息。所有 SQLite 表的行数及内容指纹在卸载、重装、启动、正常退出前后相同。本批只读取历史，没有发送新消息或调用付费模型。

临时快照、校验结果与界面文本保留在忽略目录 `target/reinstall-*`；未提交个人路径清单、配置、缓存、测试库或备份。正常关闭会回收数据库临时日志，最终核对持久文件哈希和全部逻辑数据，未将日志回收误判为历史变化。

## 尚未覆盖

本批不包含干净 Windows 首次安装、缺少 WebView2 的下载/失败/重试、MSI 实际安装和卸载重装，也没有扩展 Windows 10、多显示器或任务栏组合的窗口验收。继续按 [干净 Windows 清单](windows-clean-install.md) 执行，M1 第 4 条业务线仍处于阶段收尾；当前状态与下一批见 [正在推进](social-refactor/in-progress.md)。
