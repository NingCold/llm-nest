# 当前安排

[已完成](completed.md) · [待验收与候选](backlog.md) · [同机与加密计划](secure-local-plan.md) · [使用指南](../usage.md)

**当前仍在第四批的日常加密试用阶段。** 同机聊天、社交加密、旧资料转换与恢复核对均已实现并通过自动验证；实际账号的 AI 加密聊天、断网接续与换设备体验尚未完成。

2026-10-25，用户已完成日常账号登录、首次加密身份、设备授权，以及恢复文件下载和最终保存确认。账号中尚未创建日常 AI，不需要把此前的测试账号和记录迁入。

可信设备页面已重排：顶部只突出当前状态和下一步；完整指纹、其他设备和恢复导入按需展开；下载、勾选和最终保存确认分行显示。已建立的设备重启后直接进入解锁流程。35 组前端测试、类型检查及生产构建通过，Edge 已检查浅色、深色和 800/390px 隔离排版；隔离预览不代替真实账号功能验收。

**版本状态：** 内网 Web 页面已更新到 `0.1.1-alpha.5` 并通过健康及首页核对，服务端业务未变。本机已用 NSIS 覆盖更新至同一版本；MSI 已构建、未实装。前次 `alpha.4` 的备份、转换及安装验证见[验证记录](../validation/README.md#存量加密转换验证)。

**下一步：**

1. 创建日常 AI 并绑定本机 Agent，为它建立加密身份、保存恢复材料，再完成真人与 AI 设备的双向指纹核验。
2. 先验证加密私聊，再实际试用桌面同机、断网接续和换设备。若决定保留旧测试窗口或节点资料，再按[迁移指南](../migration.md#现有云端记录转为加密)转换并核对恢复。
3. 完成安全审查和数据核对后，开启 `CLOUD_REQUIRE_ENCRYPTION`，正式拒绝新的明文内容。当前该开关仍为 `false`。

数据库、附件及停止的测试节点已有一致备份，并完成独立数据库还原核对。旧测试历史、明文备份及旧附件保留，清理另行确认；不能把更新版本等同于所有旧资料已经加密。

独立安全审查、真实设备试用及 Windows/Linux 环境缺口继续见[待验收](backlog.md#待验收)。局域网直连、桌面重启后的离线重新登录和完整离线社交不属于本轮范围。
