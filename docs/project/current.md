**拆仓第二批已完成，下一步是 GitHub 与发布切换。** 原 `llm-nest` 保留完整历史，作为 Web/桌面客户端仓；同级 `llm-nest-server` 和 `llm-nest-agent` 已各自提取相关历史并建立独立构建、测试与说明。客户端和 Agent 通过固定 Git 提交引用协议，桌面消费指定 Agent 程序，服务端消费指定 Web 包。备份、路径及本地构建入口见[拆仓计划](repository-split-plan.md#第二批的本地结果)，完整检查见[第二批验证](../validation/README.md#拆仓第二批验证)。本轮只做本地提交，没有创建或推送 GitHub 仓库，也没有更新日常安装或服务器。

**本机 Windows 和内网网页已更新至 `0.1.1-alpha.11`。** 登录页收起了服务器设置，在最小桌面窗口也能完整显示；关闭窗口时直接检查本机 Agent 的运行锁，避免为了确认已经停止的节点再次启动子进程。服务器 Rust 沿用已部署的 `alpha.10`，聊天和加密规则不变。

服务器已释放约 16.98 GB 的旧镜像和构建缓存，备份均保留。本机已按完整清单逐个删除 8,365 个文件及 866 个空目录，合计文件大小约 6.36 GB；21 处候选均已移除，4 个保留安装包哈希一致，日常资料和最新备份仍在。此前两次删除被自动审批拒绝；随后不带 `-Force` 的逐文件删除成功，工具未说明先前拒绝原因。全局约定和清理脚本现已禁止递归删除，后续每批编译结束主动整理产物的约定已写入开发说明。此次安装前只备份实际用户资料，约 28 MB，安装前后 74 个资料文件哈希一致。详情见[本轮验证](../validation/windows.md#登录页退出与存储整理2026-10-29)。

可以继续试用保持登录、锁屏与自动解锁。两项自动选项都默认关闭，各自最多有效 30 天；新设备仍需授权，登录成功不会直接获得聊天密钥。具体规则见[账号](https://github.com/NingCold/llm-nest-server/blob/main/docs/design/accounts.md#登录会话与本机解锁)与[加密方案](../design/encryption.md#本机锁定与自动解锁)。

本批源码与隔离验证已通过。最终安装版的启动和重新连接正常，保持登录选项可用且默认未勾选；更新前已备份，原聊天、设备资料和任务统计保持。本次未登录日常账号，也未开启自动选项，账号内的真实重启和解锁仍待试用。检查范围见[本批验证](../validation/README.md#保持登录与本机解锁验证)。

此前第四批内网日常恢复收尾已完成：`alpha.9` 最终回归、Tailscale 内网完整后端与 Web 部署、NSIS 实际覆盖安装均已完成，`CLOUD_REQUIRE_ENCRYPTION=true`。这次完成的是授权内网试用切换，不是公开发布或全面安全验收，也不覆盖本批新增的登录和锁屏行为。

Edge 第二可信设备已用已有恢复文件恢复。修复本机密钥投递造成的旧通道失配后，双方显式接收恢复授权，桌面云端、桌面同机与 Edge 均按十个原 ID 逐条核对全部正文可读。日常 Agent 运行、AI 在线，同机显示已同步，密文与备份覆盖、权限身份和调用次数均核对通过；未新建身份或增加模型调用，Edge 保留。具体证据见[Windows 记录](../validation/windows.md#日常可信设备恢复与顶栏复查2026-10-25)。

顶栏统一后，用户已确认消息页和可信设备页真实拖动、双击最大化/还原通过，最终同机截图中头像、姓名、品牌与窗控处于同一顶部横带。其他页面未逐页人工操作；云端暂忙的自动等待/刷新已有真实 Agent 模拟回归，日常实际体验另记。
