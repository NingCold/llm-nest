# 图片消息第一批

2026-10-13。[当前进度](in-progress.md) · [消息](02-conversations-and-messages.md) · [意识系统](03-consciousness.md) · [接口](07-api-and-events.md)

## 本批范围

私聊和群聊可以选择、拖入或粘贴 PNG、JPEG、WebP，预览并移除后发送。允许纯图片或附带文字，每条最多 4 张，单张不超过 4 MiB、合计 8 MiB，边长不超过 4096。原图不重新编码或自动压缩；发送时会把用于回复的图片传给所选模型服务。

历史图片按需加载、点击放大，聊天列表和回复引用显示图片提示。文字编辑保留原图，撤回清空正文、图片及修订内容；相关记忆、摘要和群引用沿用既有来源失效规则。群聊“私聊继续”可带入选中的原图。普通历史、搜索定位、群来源预览和管理员只读账号视角使用相同展示组件。

发送失败保留当前图片和重试 ID，切换聊天保留各窗口草稿。文字、提及、回复与群引用可存浏览器草稿；图片只存在本次应用内存，刷新或关闭后需重新选择，输入区明确显示提示。含图草稿不会持久化命令 ID，避免重开后把同一个 ID 用于已经失去图片的正文；在飞发送成功只清掉已发送图片，不清掉后来添加的图片或文字。

## 保存、权限和协议

图片由 SocialFeature 校验 base64、真实类型和完整解码，限制分配与尺寸，再与真人消息、计划和回执同事务保存。SQLite 沿用 MessageBody 的二进制 DTO，无新迁移，仍为 v13。存储总量按原始字节计算；历史 DTO 只返回 `{index,mime,byteLength}`，不把图片字节放进启动快照或事件。

读取需要消息 ID、body part 索引及 revision；修改或撤回后拒绝旧版本请求。普通读取复核实际操作者的当前成员身份；账号视角经独立接口，在同一只读事务复核管理员与目标账号的成员身份。HTTP 返回 `{mime,data}` 并禁用缓存，IPC 共用业务，不接受路径、URL 或任意 operatorId。图片解码在 blocking worker 执行，不占用异步执行线程。

修订命令只接受新文字，事务内保留当前附件。历史文字修订的命令摘要格式继续保留，重复请求在撤回后返回当前撤回状态，不因附件已经清空而改变重试身份。旧修订或回执不能重新恢复原图。

OpenAI Chat 使用 image_url，Responses 使用 input_image，Anthropic 使用 base64 image source，Gemini 使用 inlineData。转换在协议层完成，不静默忽略图片或切换模型。接口格式核对：[OpenAI](https://developers.openai.com/api/docs/guides/images-vision)、[Anthropic](https://platform.claude.com/docs/en/build-with-claude/vision)、[Gemini](https://ai.google.dev/gemini-api/docs/image-understanding)。当前目录没有视觉能力声明，服务拒绝时保留已保存图片和失败状态，提示确认模型是否支持图片。

意识系统以尺寸估算图片输入成本，另设每次请求 16 张、原始字节合计 16 MiB 上限。必要原文和明确引用不能被静默裁掉；较早普通记录按预算截取。跨群引用使用真实图片 part，不将二进制数组序列化成文本。估算并非各模型的精确计费；实际用量仍取模型返回。分段摘要仍只读取文字和附件占位，不自动描述画面。

## 验证

- Windows MSVC：受影响的 ai-client、storage、social-feature、web-server、tauri-frontend 共 215 项测试通过，覆盖原生协议格式、文件校验、图片预算、来源读取与历史导出；格式检查和 Clippy 完成，Clippy 保留既有告警。
- Web：类型检查、13 组测试脚本、生产构建；覆盖选图/粘贴/拖放、数量与尺寸、输入法确认、图片重试、草稿不写二进制、迟到回执保留新输入，以及两条传输接口。
- HTTP 隔离验收：图片原始数据、纯图/图文、重启读取、修改/撤回及旧命令重试、错误文件、权限、真实 provider 请求中的图片、服务拒绝、共同群图片接续和导出占位。有效双图请求的原始图片约 5.6 MiB，验证跨过默认 HTTP/旧序列化大小限制仍能保存与读取；三图合计超 8 MiB 拒绝。`social_acceptance.py` 完整回归、`--only-images` 专项与 `acceptance.py` 历史导入/worker 回归均通过。
- 浏览器实际操作：选图、剪贴板图片粘贴与移除、切换聊天保留图片草稿、纯图片发送、刷新后显示历史与放大预览，并核对图片加载后仍在聊天底部。模型为本机模拟服务；未做付费识图验收。

验收同时修正旧导出脚本的竞争：无模型账号仍可能有尚未开始的合并计划，比较导出前后状态之前先等该计划收尾；不能把后台调度变化误判为导出写入。图片载入改变消息高度时，正常跟随底部的聊天继续滚动，翻历史时不强制拉回底部。

## 后续

本批没有更新本机安装程序。桌面文件选择、系统粘贴与拖放尚待 Windows/Linux 实机验证；Tauri 已关闭原生文件拖放拦截，让共用 Web File 输入接收文件。源码编译与 IPC 测试不代替原生交互验收。

下一批建议做原图另存为和聊天导出携带图片文件。现有 Markdown / JSON 导出仍只包含附件占位。跨重启图片草稿、自动缩放/压缩、动态图、通用文件、视觉能力筛选、图像描述/OCR 和图片语义检索后续单独实现。
