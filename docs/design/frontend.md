# 界面与桌面

聊天加密使用官方 Matrix SDK，先完成设备授权或恢复，再显式启用 sealedV1；消息强制验证设备和账号 master 双签，无法验证时不回退明文。角色、模型、记忆与每 AI 摘要走分范围密文资源 CAS，离线可保留待同步命令，界面区分云端保存与当前节点应用。默认输入草稿仍是本机明文，SDK 密钥库使用独立口令保护。加密附件、引用、约定、完整搜索和导出由授权客户端处理；未启用窗口保留原流程。存量转换和部署切换的范围见当前进度。接口见[加密契约](crypto-contract.md)，联调见[当前安排](../project/current.md)。

[设计总纲](overview.md) · [接口](api.md) · [运行与配置](runtime.md)

Web 与 Tauri 默认共用云端真人与 AI 私聊、群聊界面。当前进度见[当前工作](../project/current.md)，环境与实测范围见[验证入口](../validation/README.md)。

## 默认云端页面

`client/web/src/App.tsx` 默认加载 `cloud/App.tsx`。Web 与 Tauri 共用 CloudApp，提供邀请注册、邮箱验证、登录/找回密码、公开资料与登录会话管理、通讯录和真人私聊。按名字或完整账号 ID 查找联系人；同一对账号总是打开同一个私聊。“我的账号 → 我管理的 AI”已提供云端 AI 创建、配对/更换/撤销和节点状态；群创建/成员与角色管理、提及/回复、多 AI 任务、联系人屏蔽和 AI 启停已接入；节点记忆、各 AI 私有摘要与群话题接续也已接入；有限自动接话、暂停/结束和一次性约定已接入；公开资料与管理员名单、只读账号查看、角色/模型在线配置与桌面本机 Agent 配置/配对/启停及托盘已接入。

界面持续沿用原有设计：消息与通讯录是两个主入口，自己的账号位于左下角，设置提供外观与关于。`cloud/App.tsx` 管理认证、云端状态、订阅与草稿，`cloud/AuthPage.tsx` 提供登录等认证页面，`cloud/Workspace.tsx` 接入登录后的界面，并复用 `chat/components/SocialSidebar`、公共组件与 `chat/social.css`。更换数据来源不另起一套聊天布局，也不加载旧本地业务。实现与实际安装包的验证状态分别记录，构建通过不等于已更新用户安装程序。

消息页支持文字、PNG/JPEG/WebP、普通文件、自己的消息编辑/撤回、未读与手动未读、置顶、正文搜索及原消息前后定位。图片预览与附件读取始终使用当前消息 revision；修订后丢弃旧加载结果，撤回不显示旧正文或附件。导出从服务端读取完整聊天窗口，附件可选；浏览器下载 Blob，桌面通过系统保存对话框写入原字节。

Web 使用同源 fetch/EventSource；Tauri 使用 `cloud_request`、`cloud_subscribe`、`cloud_unsubscribe`、`cloud_save_download` 和 Channel 转发同一云端 API。原生层默认只保存内存 Cookie，Windows 可显式选择 30 天保持登录并由当前用户 DPAPI 保护令牌；重启仍联网核对会话，令牌不交给网页脚本。保持登录与本机自动解锁分别默认关闭，非 Windows 原生端暂不支持，规则见[账号设计](accounts.md#登录会话与本机解锁)。服务器地址保存在本机；切换账号或服务器会失效旧请求和订阅。测试 CA 仅通过启动环境 `CLOUD_CA_CERT_FILE` 指定，不关闭证书校验。

桌面启动或点击连接时实际读取 `/me`：未登录的 401 表示服务已连通，可以继续登录；网络、证书及其他 HTTP 错误保持未连接并显示原因。地址交给原生层校验通过后，统一保存 origin 作为草稿命名空间。输入地址发生变化时停止使用原连接登录，连接过程中显示进度，不将“地址已保存”当成连接成功。

持久 `change` 事件触发重新读取权威快照与相关聊天；只有读取并应用成功才推进游标，断线用最新游标重连。正文搜索和上下文定位不自动确认已读；正常聊天只有前台聚焦、页面可见且滚动到底部时才确认同快照的已读位置。身份来自当前会话，不切换全局操作者读取其他账号。

草稿复用 `chat/draft-storage.ts`，以服务器/实际账号/窗口隔离，文字、结构化提及、回复目标和附件 Blob 与发送命令原子保存。未知结果保留原 requestId 手动重试，不自动发送，成功清理原快照并保留期间新输入。关闭窗口先等待附件读取与草稿写入；失败保留窗口。桌面不再包含旧本地 Runtime 与业务 IPC；窗口操作不依赖云端登录成功。关闭窗口不停止远端服务，本机 Agent 可通过独立进程及托盘继续运行。

## 已确认的云端创建与管理方向

`cloud/AiManagement.tsx` 提供云端 AI 创建与管理列表，`AiDetails.tsx` 区分公开资料、管理员、节点、在线配置和只读账号视角。创建者成为初始管理员，创建和查看都保留当前真人身份。任一当前管理员可修改公开资料、启停 AI、管理节点与在线档案；只有初始管理员可增删真人管理员，不能移除初始管理员。云端资料和名单按各自版本提交，未知结果保留原命令重试。

未启用加密的管理路径中，`AiConfiguration.tsx` 从当前在线节点读取角色、模型选项、思考强度、温度、输出上限和自动 token 预算。节点未声明 profileManagement 时不显示可编辑档案；离线与超时单独反馈，不排队提交。未知保存结果保留同一请求，刷新当前档案或重试不复制角色正文到持久草稿。远程表单没有 endpoint 或 Key 输入。

`AiAccountView.tsx` 手动读取目标 AI 当前窗口快照和消息分页，支持附件预览/保存并逐次复核权限。不使用该 AI 的身份登录，不代发、不改变已读，不复用真人聊天的订阅；权限或附件读取失败清除当前结果。只读查看范围是聊天，不包含该 AI 的个人通讯录、记忆代编辑或导出。

桌面 `LocalAgentPanel.tsx` 通过原生 `local_agent_status/setup/pair/start/stop/models` 管理当前服务器和真实登录账号的私有目录，网页只提供远程节点流程。配置向导可选择自带目录的模型或本机 provider 参数，Key 只送本机原生层保存并注入独立子进程环境，不经云端 API。配对进度显示安全 JSON 行中的配对码，授权绑定仍走云端真人会话；启动成功须观察到托管实例，不能把进程已创建当成已启动。

主导航继续使用“消息 / 通讯录”，通讯录可并列真人与 AI，公开资料使用同一结构。AI 管理统一放在“我的账号 → 我管理的 AI”，涵盖自己获授权管理、从官网或桌面创建、在本机或服务器运行的 AI。管理权与联系人关系独立，创建后不强制添加联系人。

创建完成进入该 AI 的管理页，提供“与它聊天”（打开唯一私聊）、“管理 AI”（内部设定、模型、节点）和“查看它的账号”。查看时明确显示被查看的 AI 与实际管理员，采用只读视角，不提供人工代发。节点采用单个有效节点、管理员手动更换。

本机 Agent 作为独立进程运行，关闭聊天窗口时默认继续后台运行；首次说明提供继续后台、停止并退出和取消。继续后台时隐藏主窗口并保留托盘，重新打开后解除输入和草稿关闭锁。托盘提供打开、停止本机 Agent 和停止并退出；显式退出也取消本机待配对进程。草稿保存或本机状态检查失败时保留窗口。远程节点不受影响，本机休眠或关机则本机 AI 离线。

管理页区分云端公开资料与节点内部资料。以下描述未启用加密的在线转发路径；加密资源按前述 CAS 与 applied 状态确认。模型选择、生成参数、角色设定、显式记忆和各 AI 的窗口摘要通过云端复核授权后转发在线节点；节点保存成功才显示成功，普通配置只用于新运行。节点离线时内部资料不可远程读写，不排队提交；超时显示“结果未确认”，沿用同一 requestId 查询或重试。模型 Key 只在节点本地填写，网页不提供 Key 输入。界面按节点实际支持的能力展示管理项，外部 Agent 不必具备自带 Agent 的所有编辑能力，语义见[API 设计](api.md)。

聊天和联系人详情提供对应窗口的显式记忆入口，云端按成员与来源范围授权后转发节点。管理员在有窗口访问权时，还可打开所选 AI 的私有摘要与专用模型设置；普通成员没有这个入口。摘要不再是群成员共用的资料，完整 AI 内部配置仍归“我的账号 → 我管理的 AI”。

`cloud/Participation.tsx` 在聊天详情显示接话规则、连续发言和自动次数，提供窗口/AI 暂停、恢复、结束，以及一次性约定与免打扰。群主/管理员维护全群设置，成员可在授权开启后创建和取消自己的约定；未确认命令在本次登录内保留原 ID 与内容重试，设置草稿不被 SSE 刷新覆盖。

未启用加密时，`cloud/Consciousness.tsx` 管理在线记忆和摘要；节点离线、读取失败和空列表分开显示。未知保存结果在本次登录的内存中按服务器/账号/AI/窗口保留原命令，可原样重试，或读取当前资料后明确结束原操作；不把记忆正文写进持久客户端草稿。`cloud/References.tsx` 提供群原文选择与预览，确认后将来源 ID/版本加入已有唯一私聊草稿，保留文字和附件，不自动发送。草稿与待确认发送快照一同保存引用元数据，发送与预览再次检查来源。

网页与桌面的聊天统一经云端 HTTPS/SSE，实际操作者由服务端认证；桌面 IPC 仅用于系统交互和本机节点管理。草稿按服务器、实际真人账号和窗口隔离，切换服务器或账号不能串用。客户端断网时保留草稿；节点离线时云端仍可保存消息，界面分别显示客户端断网、节点离线、AI 停用，以及消息已保存和执行失败，不能将保存消息等同于 AI 已开始执行。

节点恢复只处理尚未开始且仍有效的任务，过期不补发；已开始但结果不明的调用不自动重试。取消后的旧结果由云端拒收，界面不承诺已经发出的模型调用立即停止或免除费用。运行和迁移的完整范围见[已确认约定](../project/cloud-plan.md#已确认的运行与迁移约定)。

### 视觉与布局

共用 React 界面参考 Codex 的连续表面与紧凑侧栏，采用中性灰白 / 炭黑底色与克制的蓝色强调，继续使用已有 Tailwind、Radix 和 Lucide；社交语义样式集中在 `chat/social.css`，设置通过同一组变量衔接。无需增加动效库、远程字体或图片依赖。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 主背景 / 侧栏与面板 | `#ffffff` / `#f6f6f6` | `#181818` / `#202020` |
| 正文 / 辅助文字 | `#242424` / `#747474` | `#ededed` / `#a0a0a0` |
| 边框 / 链接与焦点强调 | `#e8e8e8` / `#3573c4` | `#303030` / `#8cb8ed` |
| 主操作按钮 | `#242424` 配白字 | `#ededed` 配炭黑字 |

聊天正文与输入为 15px，表单与联系人名称为 14px，列表摘要和按钮为 13px，时间及辅助说明为 12px，AI 标签为 11px。桌面将主导航、列表与自己的账号合为 288px 侧栏，“消息 / 通讯录”横向切换；聊天顶栏 72px，消息与输入区限制在 800px 居中。真实聊天的 AI 正文去掉外框，自己的消息为柔和灰色气泡，输入区为低阴影圆角表面；Markdown 表格和代码在自身区域横向滚动。

大窗口的详情占独立一栏，1050px 以下为覆盖面板，700px 以下为全宽详情。850px 以下采用列表 / 内容切换；700px 以下在列表和账号页使用底部导航，进入聊天后隐藏底部导航，用聊天顶栏返回。设置在手机宽度下改为顶部横向分类。浏览器视口检查不代替手机软键盘实机验收。

公开账号资料使用紧凑身份区及简介、ID、关系区，不使用大封面；真人与 AI 仍共用资料结构。管理页使用横向账号选择、身份与操作区、内部设定 / 执行配置、管理员 / 运行状态；宽窗口两列，窄窗口一列。长名称在选择器中截断，在详情中换行，选中账号保持可见。普通资料不展示执行参数。

搜索框聚焦使用外层中性细边与轻背景，避免输入内部叠加外框；其他按钮与输入保留可见键盘焦点。消息列表显示当前窗口的未发送草稿。生成状态标注具体发送者，停止按钮明确当前 AI 回复，继续发送仍可用。弹窗保留 Radix 的键盘行为，关闭后回到触发按钮；主导航与当前列表项有 `aria-current`。颜色过渡为 160ms，详情进入为 180ms，桌面首次界面淡入为 220ms；减少动态效果偏好会关闭动画与过渡。


### 本机未发送草稿

未发送草稿将文字、图片、文件与提及/回复/群话题引用一起保存在 IndexedDB，刷新或重开同一浏览器地址/桌面应用后恢复。按实际真人账号与窗口隔离，恢复完成后才能编辑；保存中、保存成功、保存失败及重试入口直接显示在输入区。多个页面修改同一草稿时提示冲突，不覆盖另一页的内容。

发送前先持久保存原内容与 requestId；结果未知时保留独立快照，重开后可查看原内容、手动重试或放弃重试，不自动发出消息。放弃不撤回可能已送达的消息。成功回执清理对应附件和原草稿，保留等待期间新增的内容。Web 在还有未完成附件读取/写入、保存错误或未确认的图片处理时，通过 beforeunload 提示；桌面关闭流程见下文。草稿只在当前浏览器或桌面 WebView 保存，不属于服务器历史、跨端同步或整库备份，清理网站/应用浏览数据会删除草稿。实现与验证见[存储与迁移](storage.md)。


### 桌面窗口与关闭

Windows/Linux 使用内容区右上角窗口按钮，不保留系统标题栏。侧栏空白及聊天、账号等页面头部支持原生拖动和双击最大化/还原；交互元素和搜索框不拖动，正文保留文字选择。窗口操作独立于网络连接及登录状态，不依赖旧宿主初始化。Linux 当前布局的真实 GNOME 复验仍见[Linux 状态](../validation/linux.md)。

关闭先请求当前页面完成附件读取与草稿事务，失败或超时保持窗口可用。本机 Agent 存在时按后台、停止退出或取消处理，继续后台及取消会解除页面关闭锁；远程节点独立运行。详细关闭命令见[API](api.md#桌面草稿关闭协调)。

### 搜索、附件与导出

正文搜索和上下文定位复核当前权限，不自动确认已读。加密窗口在授权客户端解密后完成搜索和完整导出，未加密窗口使用云端接口。图片和文件读取按消息 ID、索引及 revision，旧异步结果不能覆盖当前窗口。默认导出 Markdown，可选 JSON；包含图片或文件时使用 ZIP，不把记忆、思考、内部档案和秘密放入聊天导出。

Web 使用浏览器下载；桌面通过 cloud_save_download 或 cloud_save_blob 打开原生保存对话框，在实际写入成功后提示已保存，取消与失败分别反馈。不向 WebView 开放任意路径写入或旧本地 SocialFeature 导出入口。
