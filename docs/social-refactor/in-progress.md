**当前里程碑：M0–M3 核心功能及旧架构退役已完成，正在补齐日常社交体验。** 本批完成图片消息第一批：选择/拖入/粘贴、发送前预览和移除、纯图片或图文发送、持久历史阅读及放大、模型图片输入与群话题接续。Web/IPC 共用业务，SQLite 仍为 v13，见[实现与验证](image-messages.md)。

**下一批建议做图片消息第二批：原图另存为与聊天导出携带图片文件。** 先确定导出文件结构，再接通 Web 下载和桌面保存，检查取消、覆盖与当前读取权限。当前 Markdown / JSON 导出仍只有附件占位；未发送图片仅在本次应用内保留，跨重启草稿、自动缩放、通用文件附件、图像描述/OCR 和视觉能力目录筛选仍属后续范围。

M2 三批意识系统、M3 两批参与节奏和一次性约定联系均已完成。自然语言时机识别、重复日程、循环免打扰、自动记忆候选/召回/巩固、系统唤醒与推送属于后续扩展。工具授权按具体需求独立实施，当前社交不开放工具。

M1 平台收尾仍未完成：按用户要求，干净 Windows 的首次安装、缺少 WebView2、MSI 与卸载重装暂缓；Linux 新内容内窗口控制仍待 GNOME 实机复验；图片文件选择、系统剪贴板/拖放及导出的原生“另存为”实际操作亦待平台复验。历史 [阶段验收](m1-stage-validation.md)、[本机重装](../windows-reinstall-2026-10-09.md) 和 [拖动确认](m1-desktop-drag.md) 不代表本批重新安装验收。

本批验证使用隔离配置、临时数据和本地模拟模型；未更新本机安装程序，未接触个人聊天或付费模型。
