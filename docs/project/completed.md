# 已有能力

这里列出当前源码和内网试用版已提供的能力。[当前安排](current.md)列出实际安装、部署与公开版本；首次操作见[使用指南](../usage.md)。

## 账号和聊天

- 真人凭邀请注册、验证邮箱、用密码登录。可以添加、移除或屏蔽联系人。移除后保留历史，重新添加仍使用同一个私聊；屏蔽限制新的私聊，共同群里的互动照常。
- 每对账号有一个长期私聊，每个群有独立窗口。群主和管理员管理成员；当前群成员共享完整群历史。加密群的可信设备可以获得历史密钥。
- 网页与桌面支持文字、图片、文件、编辑与撤回、未读和置顶、正文搜索，以及携带附件的单窗口导出。未发送的草稿留在当前设备。

## AI 和它的记忆

- AI 有独立账号和公开资料。创建者是初始管理员，可以授予或撤销其他管理员；管理员在“我的账号 → 我管理的 AI”管理角色、模型和运行节点，也可只读查看获准访问的聊天。
- 一个 AI 同时由一个有效节点运行，一个节点可以运行多个 AI。Agent 调用本机或远程模型，模型密钥留在节点。桌面可管理自带 Agent，关闭窗口后可让它留在托盘继续运行。
- 每个 AI 保留显式记忆；管理员可按窗口开启分段摘要。群话题可选取共同可见的原文带回私聊。来源被撤回或访问权丢失后，相关资料停止参与后续对话。
- 群里默认用提及或回复请 AI 发言，可开启有限自动接话。支持暂停、结束、一次性约定联系和免打扰。云端控制发言次数，节点控制模型预算；结果未知的调用不会自动重做。

## 历史、加密与换设备

- 私聊、群聊、附件、约定正文和 AI 资料支持端到端加密。云端同步密文，可信客户端或节点解密。AI 的角色、模型参数、记忆和摘要可加密同步，模型 Key 留在节点。
- 账号登录和本机解锁分开。新设备可通过已有可信设备或恢复文件取得授权；已同步的历史在有密钥的客户端可读，不需要对方或其 Agent 在线。
- 桌面和同机 Agent 可直连。已有会话断开云端后，普通文字私聊可保存在本机；重连时核对权限并补传，不再次调用模型。
- 旧版 v13 数据可以先备份、预览，再迁入云端；换节点可交接已有 AI 的资料。可迁移的内容与所需凭据见[迁移指南](https://github.com/NingCold/llm-nest-server/blob/main/docs/migration.md)。

客户端、服务端和 Agent 在三个仓库独立构建；连接器是服务端仓中的独立包。[设计总纲](../design/overview.md)说明各自负责什么，[待验收与候选](backlog.md)区分已实现但还缺实机验证的能力和未来功能。
