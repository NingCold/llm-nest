# 首版范围与当前安排

LLM Nest 处于**邀请制 Alpha 的内网日常试用阶段**。首版要让受邀的人从网页或桌面加入，在同一个长期私聊或群聊中和真人、AI 保持联系。AI 有自己的账号，由管理员连接的 Agent 运行；普通聊天者不用安装 Agent 或提供模型密钥。

## 首版交付什么

- **加入和聊天。** 凭邀请注册、验证邮箱，在“消息”和“通讯录”中找到对方，发送文字、图片和文件，重开客户端后能继续原来的聊天。
- **与同一个 AI 长期交流。** 管理员可创建 AI、连接本机或远程节点，调整角色与模型。AI 可以记住明确交代的事，把群里的话题接回私聊，并按群规则接话或在约定时间联系。
- **保护并延续资料。** 试用站要求新内容端到端加密。可信设备可读回历史；换设备可用已有信任或恢复文件授权。同机文字私聊可在断开云端后继续，重连再同步。

云端改造第 0–5 步、同机与加密四批、三仓拆分均已完成。详见[已有能力](completed.md)；各环境实际验证到哪里见[验收记录](../validation/records.md)。

## 下一步：让受邀者自己开始聊天

下一批沿着一次真实入门体验走：**收到邀请 → 注册并保存恢复文件 → 找到联系人、开始加密私聊并加入群聊 → 重开客户端或换到另一台可信设备，读回原来的对话**。想管理 AI 的人再走一次创建、连接节点、取得第一条回复的流程。以受邀者能凭界面和[使用指南](../usage.md)独立完成为准，优先解决需要开发者在旁指导的地方。

随后为邀请试用选定一组相互兼容的网页、桌面、服务端和 Agent 版本，给试用者同一份入口和说明。目前站点仅限授权内网，使用测试证书和测试收件箱；扩大邀请前需让受邀者能正常信任站点、收到验证及找回密码邮件。

开屏性能专项已收尾，日常试用若再出现明显等待，可按[Windows 记录](../validation/windows.md#解锁与设备目录同步优化2026-11-01)定位。第三方 Agent SDK、局域网直连与更复杂的自动记忆暂不纳入首版；其他缺口见[待验收与候选](backlog.md)。

## 现在使用的是哪个版本

| 环境 | 客户端 / Web | Agent | 服务端 |
| --- | --- | --- | --- |
| 本机与内网试用 | Windows `alpha.21`；站点 Web `alpha.20` | 桌面附带 `alpha.14` | `alpha.13` |
| 已公开发布的 Alpha | Windows、Linux 和 Web `alpha.13` | `alpha.13` | `alpha.12` |

公开安装包和内网试用版有功能差异。例如桌面创建加密 AI 的完整向导在本机试用版可用。
