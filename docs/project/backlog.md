## 已安排与后续待办

同机文字私聊第一批已实现并通过自动验证，后续按[同机聊天与加密执行计划](secure-local-plan.md)进入私聊、设备恢复和 AI 资料加密。D1–D9 与 S1–S5 作为后续加密批次的设计基线；现阶段不声称端到端加密已实现。批次范围和结束条件只在该计划维护。

**局域网直连已列入待办。** 待有明确的跨设备需求时，在设备配对后复用同机聊天的账号、消息和同步规则，再处理地址变化与连接方式；不并入第一批，不扩成公网点对点网络。浏览器完整离线运行、离线重新登录和离线群聊也不属于当前第一批。

## 待验收

这些是已有功能的验证缺口，暂停或缺设备不等于通过。本机日常流程结果见 [Windows](../validation/windows.md)，Linux 边界见 [Linux](../validation/linux.md)。

| 范围 | 仍需检查 | 安排 |
| --- | --- | --- |
| 同机私聊 | 桌面实际操作、Linux 本机通道、日常部署；Windows 原生单测启动错误 | Windows Agent 真实进程、模拟模型和 PostgreSQL 已自动验证；桌面编译不代替实际点击验收 |
| Windows 安装 | 干净系统 NSIS/MSI 首次安装、缺少 WebView2、覆盖与卸载重装、MSI 实际安装 | 用户自 2026-10-10 起暂缓；恢复时按[安装清单](../packaging/windows-clean-install.md)执行 |
| 其他 Windows 环境 | Windows 10、其他显示缩放与启动外观 | 待对应设备；Windows 11 150% 不代替其他环境 |
| 专项故障 | 真实 WebView 中注入草稿存储失败，以及附件读写瞬间关闭 | 已有自动测试，不计为原生故障注入；随实际问题或专项安排补验 |
| Linux 当前界面 | 新无标题栏布局的 GNOME 窗口与输入、附件选择/剪贴板/拖放、处理、草稿重开及保存导出 | 用户于 2026-10-20 明确暂缓 |

## 未排期候选

真人多账号、邀请注册、联网聊天、节点意识资料、接话约定、AI 管理、桌面本机运行和命令行迁移已实现，见[云端社交与 Agent 接入计划](cloud-plan.md)。后续日常试用按[当前安排](current.md)推进，不自动增加新阶段。

以下不是待清空的任务队列，也不是首版新增完成条件。根据日常反馈选择完整目标，再确定范围。

| 方向 | 可考虑的能力 | 当前边界 |
| --- | --- | --- |
| 意识与交流 | 自动记忆、语义召回、后台巩固、自然语言群话题定位/接话/结束约定、显式转发 | 当前采用显式记忆、来源引用、摘要和确定性参与规则 |
| 文件和图片理解 | TXT/Markdown 正文读取、PDF/Office、OCR、图片描述及动态图 | 普通文件只向模型提供名称、类型、大小；图片能力声明不等于真实识图验收 |
| 查找和数据管理 | 语义与附件搜索、大文件存储、流式 ZIP、跨端草稿、定期在线备份、聊天导出再导入、可视化或分批迁移 | 已有旧库迁移、节点资料包及隔离部署备份恢复验收；普通聊天导出不等同整库备份 |
| 约定和通知 | 重复日程、全局免打扰、条件监控、系统唤醒和离线推送 | 云端已支持一次性约定与窗口免打扰；云端与节点在线时不依赖聊天窗口存活 |
| 账号管理 | 角色模板、初始管理员转让、人工代发、独立账号订阅 | 当前支持公开资料、管理员授权、在线角色/模型和只读查看；上述扩展未排期 |
| 工具授权 | 具体工具的授权撤销、白名单执行和中断收尾 | 社交当前无工具；先明确需求和权限，角色文本不能授予权限 |

MCP、任意插件、通用编码代理、知识库与工作流不在当前范围。
