# 桌面依赖的版权声明

[copyrights.json](copyrights.json) 按 crate 版本记录上游 `COPYRIGHT` 的来源。桌面包只列出目标平台用到的组件；GTK 和 Rand 家族中使用同一份版权声明的组件分别列出来源，共用正文。许可证正文由 cargo-about 按 [about.toml](../../about.toml) 生成。

Linux 的 `sigchld 0.2.4` 声明采用 MIT，但[发布包](https://static.crates.io/crates/sigchld/sigchld-0.2.4.crate)和[对应源码提交](https://github.com/oconnor663/sigchld.rs/tree/07b95e2fe38b18b376b0f635f2766bf2e641b80b)均未附许可证正文或版权行。随包声明注明 MIT 正文由工具生成，版权署名待上游确认。
