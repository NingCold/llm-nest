- EXIF 方向及透明图片处理尚未操作。已观察到透明原图预览，不能作为处理后仍保留透明的证据。
- 图片和普通文件的单独覆盖保存尚未操作；本轮覆盖及写入失败证据仅来自聊天 ZIP。
- 原生选择器的取消选择尚未单独操作。
- 附件正在读取/写入时关闭，以及草稿存储失败的原生界面尚未实测；现有关闭协调和草稿事务测试不替代这些实际操作。
- JSON 导出此前自动回归已测，本轮未通过原生对话框操作，不计为本轮桌面通过项。
- 以上使用模拟 provider，不证明真实模型能力；测试 EXE 不构成安装包、发布构建或安装卸载验收。代码静态审查不列为桌面实测通过项。
