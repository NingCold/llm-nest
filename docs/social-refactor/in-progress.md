先在可用 Windows 环境集中验证窗口与输入、图片/普通文件选择和拖放、草稿关闭重开、原生另存为及取消/覆盖。共享前端、HTTP/IPC 回归和 Web 实测已有证据，下一批重点确认原生桌面行为。

Linux 新窗口布局需要 GNOME 实机复验。干净 Windows 首次安装、缺少 WebView2、MSI 与相应卸载重装继续按用户要求暂缓，不因 Web 收尾完成而标记通过。逐项范围只在[M1 剩余范围](pending.md#m1-剩余范围)维护。
