# 当前安排

[已完成](completed.md) · [待验收与候选](backlog.md) · [同机与加密计划](secure-local-plan.md) · [使用指南](../usage.md)

**当前仍在第四批，日常加密私聊和桌面同机断云接续已经跑通。** 接下来验证实际可信设备恢复，并完成整体加密收尾；尚未完成全局强制加密切换。

2026-10-25，用户已完成日常账号登录、本机解锁、首次加密身份和恢复文件保存。日常 AI“小巢”已创建、加入通讯录并绑定桌面本机 Agent，采用 `chatecnu / ecnu-plus`，模型 Key 只引用本机环境变量。双方根据各自本机取得的三项指纹完成信任，AI 的恢复文件已保存到节点目录之外的受限私有目录。

小巢的角色与模型资料已以密文同步并由节点应用。唯一私聊开启加密后，两轮真实云端对话成功，第二轮准确接续前文；重新进入聊天仍可解密历史。随后在已安装的 `alpha.5` 中开启同机私聊，联网和断云各完成一轮真实回复；断云期间记录先保存在本机，恢复连接后自动补传，没有新增模型调用或云端任务。断开的是测试服务的 HTTPS 代理，模型互联网连接保留，未验证全网断开或本地模型。代理已恢复，临时恢复定时器已取消。具体证据见[Windows 日常同机记录](../validation/windows.md#日常同机私聊与断云接续2026-10-25)。不需要把此前的测试账号和记录迁入。

可信设备页面已重排：顶部只突出当前状态和下一步；完整指纹、其他设备和恢复导入按需展开；下载、勾选和最终保存确认分行显示。已建立的设备重启后直接进入解锁流程。35 组前端测试、类型检查及生产构建通过，Edge 已检查浅色、深色和 800/390px 隔离排版；隔离预览不代替真实账号功能验收。

**版本状态：** 内网 Web 已更新到 `0.1.1-alpha.6` 前端覆盖层，旧 Web 与镜像已备份，健康及实际首页资产核对通过；后端可执行文件沿用原镜像层。本机已用 NSIS 覆盖安装 `alpha.6`，安装版本及配套 Agent 摘要核对通过，并从原内网入口启动到“服务器已连接”；MSI 只构建、未实装。用户已重新登录、解锁，聊天头与详情的原生界面复验通过，并从界面启动本机 Agent；当前节点运行中。部署核对结果见[验证记录](../validation/README.md#聊天布局与-web-更新)。

聊天布局调整已在 Web 部署：顶部保留头像、名字、简短连接状态与必要操作，密钥分享和同机操作放入聊天详情，并修整表单、窄屏和桌面窗口控件避让。完整前端 35 组测试、类型检查及 Edge 30 类主要组件的窄屏隔离预览通过；Windows `alpha.6` 已实际读回八条加密历史，聊天头、窗口控件和详情布局正常，同步重试仍为已同步。节点调用保持四次，更新与重试没有产生模型调用；这只是联网安装重启后的读回，上面的断云结果来自 `alpha.5`。

**下一步：**

1. 验证实际可信设备恢复、换设备和恢复材料读回。
2. 核对整体加密切换所需的数据与恢复结果。若决定保留旧测试窗口或节点资料，再按[迁移指南](../migration.md#现有云端记录转为加密)转换并核对恢复。
3. 完成安全审查和数据核对后，开启 `CLOUD_REQUIRE_ENCRYPTION`，正式拒绝新的明文内容。当前该开关仍为 `false`，小巢这一个私聊已独立开启加密。

数据库、附件及停止的测试节点已有一致备份，并完成独立数据库还原核对。旧测试历史、明文备份及旧附件保留，清理另行确认；不能把更新版本等同于所有旧资料已经加密。

独立安全审查、断网或中断运行后的重启恢复、换设备体验及 Windows/Linux 环境缺口继续见[待验收](backlog.md#待验收)，Linux 实机仍按用户安排暂缓。局域网直连、桌面重启后的离线重新登录和完整离线社交不属于本轮范围。
