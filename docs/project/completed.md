| 主题 | 已有能力 | 设计 |

| 聊天 | 唯一长期私聊、独立群聊、结构化提及与回复、消息修订撤回、已读未读与置顶、正文搜索及定位、图片和普通文件收发、聊天导出 | [聊天](../design/conversations.md) |
| 意识系统 | 按角色与窗口构造上下文，显式记忆、分段摘要、共同群话题接续及来源失效；图片原生输入，普通文件只提供元信息 | [意识系统](../design/consciousness.md) |
| 参与和约定 | 有限自动接话、队列和调用额度、暂停与结束交谈、一次性约定联系和窗口免打扰 | [参与](../design/participation.md) |
| 模型执行 | 独立模型与参数、协议路由、配置快照与热更新、目录同步、图片能力声明、流式终态和中断恢复 | [执行](../design/execution.md)、[运行时](../design/runtime.md) |
| 数据与界面 | SQLite 事务、目录锁、顺序迁移与显式旧历史导入；Web/Tauri 共用真实界面、附件草稿持久化、原生保存及关闭等待 | [存储](../design/storage.md)、[接口](../design/api.md)、[前端](../design/frontend.md) |
