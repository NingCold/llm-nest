# 当前安排

[已完成](completed.md) · [待验收与候选](backlog.md) · [同机与加密计划](secure-local-plan.md) · [使用指南](../usage.md)

**保持登录、本机锁屏及可选自动解锁已完成源码实现与隔离验证。** 登录/邮箱验证默认不保持登录；用户可选择绝对有效 30 天的登录会话。已有可信本机设备另可在原口令确认及恢复文件保存后开启 30 天自动解锁，默认关闭。Windows 使用当前用户 DPAPI，Web 使用当前浏览器内的封装材料；非 Windows 原生端暂不开放这两项自动选项。锁定卸载聊天与订阅，保留账号及导航位置，Agent 继续运行；手动暂停跨刷新和重启，恢复入口独立可达。具体规则见[账号](../design/accounts.md#登录会话与本机解锁)与[加密方案](../design/encryption.md#本机锁定与自动解锁)。前端 38 组、云端 66 项及 Windows 桌面 36 项测试通过，类型检查、构建和相关 Clippy 通过，详见[本批验证](../validation/README.md#保持登录与本机解锁验证)。本批尚未替换日常安装版或部署云端。

此前第四批内网日常恢复收尾已完成：`alpha.9` 最终回归、Tailscale 内网完整后端与 Web 部署、NSIS 实际覆盖安装均已完成，`CLOUD_REQUIRE_ENCRYPTION=true`。这次完成的是授权内网试用切换，不是公开发布或全面安全验收，也不覆盖本批新增的登录和锁屏行为。

Edge 第二可信设备已用已有恢复文件恢复。修复本机密钥投递造成的旧通道失配后，双方显式接收恢复授权，桌面云端、桌面同机与 Edge 均按十个原 ID 逐条核对全部正文可读。日常 Agent 运行、AI 在线，同机显示已同步，密文与备份覆盖、权限身份和调用次数均核对通过；未新建身份或增加模型调用，Edge 保留。具体证据见[Windows 记录](../validation/windows.md#日常可信设备恢复与顶栏复查2026-10-25)。

顶栏统一后，用户已确认消息页和可信设备页真实拖动、双击最大化/还原通过，最终同机截图中头像、姓名、品牌与窗控处于同一顶部横带。其他页面未逐页人工操作；云端暂忙的自动等待/刷新已有真实 Agent 模拟回归，日常实际体验另记。

**下一步：**

1. 将本批更新到内网测试服务和本机安装版，验证真实重启后的保持登录、自动解锁、手动锁定与退出，并读回原有加密历史。两项选项仍默认关闭，日常用户自行决定是否开启。
2. 继续在现有桌面与保留的网页客户端日常试用，按实际反馈修整，不自动增加新阶段。保留[待验范围](backlog.md#待验收)：修复后的真实客户端重启验读尚未执行；SDK 独立重开回归已通过，两者不混为一项。

`alpha.8` 更新前的一致备份已完成，此前私有节点资料、云端数据库与附件也已通过独立恢复核对。旧测试资料选择原样保留：27 个普通未加密窗口的 187 条消息、一个只读导入窗口的两条消息，以及 22 条终态明文约定，不转换、删除或迁入日常账号。强制加密只拒绝新明文，不改写旧记录或清理备份。

公开发布前的独立安全审查、断网或中断运行后的重启恢复、实际节点交接及 Windows/Linux 缺口继续保留，Linux 实机仍按用户安排暂缓。已验证的断云保留模型互联网连接，不能代替全网断开或本地模型验收。局域网直连、离线重新登录和完整离线社交不属于本轮范围。
