# 当前安排

[已完成](completed.md) · [待验收与候选](backlog.md) · [总计划](cloud-plan.md) · [使用指南](../usage.md)

**第 4 步“管理与本机运行”已实现。** “我的账号 → 我管理的 AI”现在可以修改公开资料、授权其他管理员、在线调整角色和模型，以及只读查看 AI 的聊天。角色设置保存在节点，收到节点确认后才显示保存成功；新回复采用新配置，已经开始的回复保持原配置。模型 Key 继续留在运行设备。

桌面提供“在这台电脑上运行”：选择模型与本机密钥、授权节点、启动或停止独立 Agent。首次关闭说明后台运行，托盘可重新打开窗口或停止节点。同一服务器、同一个真人账号共用本机节点，可连接多个 AI；远程节点不受桌面关闭影响。连接器的外部示例已补齐取消和撤权处理。

云端 31 项真实数据库测试、Agent/连接器、桌面与前端检查及部署后的模拟管理验收已通过；网页已验证角色保存确认、只读聊天和免打扰时间输入。Windows 独立窗口已完成配置、配对、启动和关闭后继续回复；用户实测通过托盘恢复窗口、继续输入和停止节点，云端确认节点离线。最终服务与 Web 已部署到授权内网，部署前保留数据库备份。本轮没有调用真实模型，详见[验证记录](../validation/README.md#云端管理与本机运行验证)。

**下一步是第 5 步：数据迁移与联网试用。** 先完成旧库备份和迁移预览，明确真人与 AI 账号映射，再将聊天与附件迁入云端、角色与意识资料迁入节点；用独立测试数据验证重复执行与更换节点，最后进入日常试用。具体范围只在[总计划](cloud-plan.md#第-5-步数据迁移与联网试用)维护。

本轮未迁移旧库、替换已安装桌面程序或日常 Agent。测试服务仍只在 Tailscale 内网使用；干净 Windows 安装与 Linux 桌面等暂停项保留在[待验收清单](backlog.md)，不以开发构建或 Web 验证代替。
