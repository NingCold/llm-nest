**当前里程碑：M0–M3 核心功能及旧架构退役已完成，正在补齐日常社交体验。** 消息列表和联系人屏蔽之后，本批单窗口聊天导出已完成：私聊、群聊及只读历史可导出完整 Markdown / JSON，保留当前消息正文和状态，Web 下载与桌面另存为共用读取与格式化。SQLite 仍为 v13，见[实现与验证](conversation-export.md)。本批不包含附件文件和重新导入。

**下一批建议做图片消息。** 先接通图片选择与发送前预览、持久保存、聊天历史展示，再让支持图片的模型读取图片；同步 Web 与桌面。通用文件附件、附件文件导出、角色模板和联网社交各自另行安排。图片消息尚未开始编码。

M2 三批意识系统、M3 两批参与节奏和一次性约定联系均已完成。自然语言时机识别、重复日程、循环免打扰、自动记忆候选/召回/巩固、系统唤醒与推送属于后续扩展。工具授权按具体需求独立实施，当前社交不开放工具。

M1 平台收尾仍未完成：按用户要求，干净 Windows 的首次安装、缺少 WebView2、MSI 与卸载重装暂缓；Linux 新内容内窗口控制仍待 GNOME 实机复验；本批原生“另存为”的实际操作亦待平台复验。历史 [阶段验收](m1-stage-validation.md)、[本机重装](../windows-reinstall-2026-10-09.md) 和 [拖动确认](m1-desktop-drag.md) 不代表本批重新安装验收。

本批验证使用隔离配置、临时数据和本地模拟模型；未更新本机安装程序，未接触个人聊天或付费模型。
