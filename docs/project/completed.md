# 已完成的能力

[当前安排](current.md) · [待验收与候选](backlog.md) · [设计入口](../design/README.md)

本地三仓拆分已完成：客户端保留原仓完整历史，服务端和 Agent 提取相关历史，各自拥有构建、锁文件、CI 和使用说明。协议依赖固定提交，客户端与服务端分别消费 Agent 和 Web 产物，跨仓加密及迁移验收通过。旧库读取与 SQL 字节保留，原模型目录修改交接至 Agent 仓并保持未提交。本轮没有创建远端、推送或部署；下一步见[当前安排](current.md)，证据见[第二批验证](../validation/README.md#拆仓第二批验证)。

当前默认入口支持云端真人与 AI 的私聊、群聊、AI 管理、桌面本机运行及命令行数据迁移。第 0–5 步的功能已实现；实现与实际验收分别记录，验证结果见[验证指南](../validation/README.md)。

`alpha.11` 已更新本机 Windows 和内网网页：登录页的服务器设置改为按需展开，最小桌面窗口无需上下滚动；退出时直接检查 Agent 运行锁，只有运行中的节点才走停止协议。新增可预览的增量编译缓存清理脚本，并将每批构建后整理产物写入工作约定。服务器已清理约 16.98 GB，本机清理的执行状态见[当前安排](current.md)；实际安装和测试范围见[Windows 记录](../validation/windows.md#登录页退出与存储整理2026-10-29)。

后续同机计划的第一批也已实现：桌面登录会话可与同机 Agent 直接进行文字私聊，断云后保存记录、恢复后同步，同一发送和模型调用不会因重试重复。支持已有节点角色、记忆及摘要，停止和重启保留中断结果，已完成自动验证。第一批建立本机执行与补传，第二批在同一路径加入端到端加密；当时不含附件和引用；第三批扩展这些能力，局域网和离线重新登录仍未提供。详见[执行计划](secure-local-plan.md)及[验证记录](../validation/README.md#同机文字私聊验证)。

第二批的私聊与 AI 资料加密也已完成自动验收。采用 Matrix 官方 SDK，提供可信设备、独立恢复文件、文字与流式回复加密、角色/模型/记忆/各 AI 窗口摘要密文同步、离线待同步与版本冲突处理，以及正常节点交接和恢复。同机断云聊天沿用原密文补传，不增加模型调用；遗忘和来源失效不会被恢复资料覆盖。详见[验证记录](../validation/README.md#私聊与-ai-资料加密验证)。

第三批将群聊、群历史分享、图片与文件、群话题接续、一次性约定正文接入同一协议。搜索和完整导出在客户端解密；同机断网私聊可携带附件与已准备来源，重连同步原结果。群权限变化不会扩大密钥分享范围，AI 重入群不会恢复旧记忆或摘要设置。旧未启用窗口与旧历史仍是明文，日常迁移与部署在第四批。详见[验证记录](../validation/README.md#完整社交加密验证)。

第四批已实现旧消息、附件和终态约定转换，保留原作者、顺序、修订、读态及来源；转换后从恢复文件独立读回全量清单，并比对转换前的内容。节点资料提供显式转换、遗忘记录保留和新节点恢复，部署可强制拒绝明文。迁移前一致备份、独立数据库还原及专项自动验收通过；日常资料是否已切换和安装状态分别见[当前安排](current.md)。

可信设备与恢复页面已按当前步骤重排：首次创建、身份建立和恢复文件保存依次引导，下载与最终保存确认分开；就绪后显示简洁状态，完整指纹及其他设备管理按需展开。恢复确认与设备信任确认彼此独立，仍须逐项核对三个指纹。该次整理的 35 组前端测试通过，并用 Edge 检查浅色、深色及 800/390px 隔离界面排版。

当前源码已加入可选 30 天保持登录、独立本机锁屏及默认关闭的 30 天自动解锁：登录会话与 SDK 解锁分开，锁定卸载聊天内容及订阅，独立恢复入口保留；手动锁定暂停自动解锁，退出清理自动材料而保留 SDK 库。Windows 用 DPAPI，Web 用浏览器内封装材料，非 Windows 原生端暂不开放两项自动选项。本批隔离验证已通过，详见[验证记录](../validation/README.md#保持登录与本机解锁验证)。`alpha.10` 已部署内网服务与网页，并实际覆盖安装本机 Windows；已验证未登录启动、重新连接和保持登录选项默认关闭，真实账号重启与解锁流程仍待试用。实际结果以[当前安排](current.md)为准。

日常账号与新 AI 已在安装版完成本机节点绑定、恢复文件保存和双向设备信任，角色资料以密文同步并应用。两轮真实云端加密私聊成功接续上下文，随后在 `alpha.5` 完成联网和断云各一轮同机回复并自动补传；云端合计八条密文消息、两个同机执行记录，原有两个云端任务不变，节点调用仍为四次。模型互联网连接保留，全网断开、本地模型和断网重启仍未验证，见[Windows 验证记录](../validation/windows.md#日常同机私聊与断云接续2026-10-25)。

日常账号已在 Edge 用已有恢复文件恢复第二台可信网页设备：新设备 ID 不同、账号主指纹相同，八条原聊天和 AI 角色资料 v1 均可读。此次没有补发历史密钥、生成新恢复文件或调用模型，网页设备按用户选择保留。实际恢复不代替独立安全审查，见[恢复验证](../validation/windows.md#日常可信设备恢复与顶栏复查2026-10-25)。

内网已启用强制加密，旧测试资料与明文备份原样保留。日常旧通道修复后，桌面云端、桌面同机与 Edge 均按十个原 ID 逐条读回全部正文，原缺失消息可读；密文、备份覆盖、原身份及五次调用均核对通过，同机显示已同步。Edge 保留，没有新建身份或额外模型调用。

聊天密钥分享和同机操作已移入详情，表单和窄屏完成整理，品牌、头像标题与窗控统一共享 72px 顶部。用户确认消息页及可信设备页真实拖动、双击最大化/还原通过，其他页未逐页人工操作；真实 Agent 模拟回归确认暂忙后自动等待、刷新且不改冻结请求，详见[验证记录](../validation/README.md#聊天布局与-web-更新)。

`alpha.9` 已修复本机未知库存被误当作 0 的 SDK 接入问题，最终完整及迁移回归、内网部署和 NSIS 实装完成。本轮第四批内网日常恢复收尾结束，转入日常试用与反馈；修复后真实客户端重启验读尚未执行，SDK 独立重开回归已通过。其他平台和公开发布前的独立审查仍按[待验收](backlog.md#待验收)保留，不称为全面安全验收。

| 群聊 | 建群、改名、增减成员、群主任免管理员及转让、退出和重新加入；当前成员共享完整群历史 |
| 群内 AI | 结构化提及与同窗口回复；多个 AI 跨节点依次发言，每个目标独立显示状态和停止；成员变化使旧任务失效 |

| 服务 | 独立 PostgreSQL 与附件目录、按登录身份检查权限、持久事件；单机容器部署、HTTPS 和私有测试收件箱 |

云端与 Web、本机节点的实际验证分别见[迁移验证](../validation/README.md#数据迁移与联网试用验证)和[管理验证](../validation/README.md#云端管理与本机运行验证)。第四批已更新内网服务和本机安装版，范围及未完成的日常资料切换见[当前安排](current.md)。

代码已按客户端、服务端、自带 Agent 和连接器组织；云端服务不依赖本地模型、SQLite 或 Runtime。独立 `agent/node` 复用模型协议与 Agent 核心；连接器可独立接入外部程序，附明确标注固定回答的最小示例。本机独立 Agent 与云端 Web 的文字、图片私聊已通过真实模型验证，远端二进制恢复/撤权联调及模拟检查分别见[节点验证](../validation/README.md#云端-ai-节点验证)，依赖边界由脚本检查。

## 保留待迁入的本地能力

以下功能在先前的本地版本中已实现，代码仍用于回归和后续迁入，当前云端界面尚未提供：

| 主题 | 已有本地实现 | 计划 |
| --- | --- | --- |
| 模型目录 | 同步外部公共模型目录和图片能力人工覆盖 | 云端管理当前使用节点已配置目录，这些本地目录工具尚未迁入 |
| 图片处理 | 发送前缩放与压缩，确认预览后加入草稿 | 云端入口尚未接入；不扩大当前第 5 步范围 |

旧本地库和节点资料已有[迁移工具](https://github.com/NingCold/llm-nest-server/blob/main/docs/migration.md)，完整旧库保留。当前支持单次 128 MiB 的云端资料、重新创建旧 AI 的云端身份，以及节点现有单来源记忆；复杂旧依赖和旧修订仍可在备份中保留，不声称全部转为节点在线能力。

先前 Windows 日常流程验收及安装更新只证明当时的本地版本。新版云端客户端没有借用这些记录声称完成平台或安装验收。社交执行仍未开放通用工具、MCP 或插件。
