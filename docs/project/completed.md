# 已完成的能力

[当前安排](current.md) · [待验收与候选](backlog.md) · [设计入口](../design/README.md)

当前默认入口支持云端真人与 AI 的私聊、群聊。第 3 步第一批已实现；实现与实际验收分别记录，验证结果见[验证指南](../validation/README.md)。

| 主题 | 当前云端已实现 |
| --- | --- |
| 账号 | 邀请注册、邮箱验证、邮箱更正与重发、密码登录和重置、退出及会话撤销；公开姓名、简介和账号 ID |
| AI 与节点 | 云端 AI 账号及初始管理员、“我管理的 AI”、配对码绑定/更换/撤销、节点在线状态；独立 Agent 的角色/模型档案、持久预算及检查点 |
| AI 回复 | HTTPS/WSS 任务与材料协议、调用前云端持久开始确认、流式检查点、停止回复、来源变更取消、原结果幂等重交；已开始而结果不明不重调模型 |
| 联系人和私聊 | 按姓名或账号 ID 查找、添加和移除联系人；两人唯一长期私聊，移除后重新添加沿用历史；屏蔽限制双方新私聊，共同群照常互动 |
| 群聊 | 建群、改名、增减成员、群主任免管理员及转让、退出和重新加入；当前成员共享完整群历史 |
| 群内 AI | 结构化提及与同窗口回复；多个 AI 跨节点依次发言，每个目标独立显示状态和停止；成员变化使旧任务失效 |
| AI 启停 | 管理员停用、恢复账号，保留历史和节点绑定；停用期间真人消息仍保存，恢复只响应新消息 |
| 消息 | 文字、图片、普通文件、分页历史、编辑与撤回；重复请求不重复建消息 |
| 列表和查找 | 各账号自己的已读、手动未读、置顶、正文搜索和消息定位 |
| 保存和导出 | 原图与文件下载、完整单窗口 Markdown/JSON 导出，可携带图片和普通文件 |
| 客户端 | 云端数据接回原有消息/通讯录布局、侧栏与视觉样式，账号在左下角，设置提供外观与关于；Web 与桌面共用源码；按服务器、账号和窗口保存本机草稿；实时同步和断线重连；桌面原生保存与关闭前草稿确认 |
| 服务 | 独立 PostgreSQL 与附件目录、按登录身份检查权限、持久事件；单机容器部署、HTTPS 和私有测试收件箱 |

此次界面接入已完成 [Web 验证](../validation/README.md#原有界面接入云端的-web-验证)，尚未更新已安装桌面程序；此前桌面联调不代表新界面已通过桌面验证。

代码已按客户端、服务端、自带 Agent 和连接器组织；云端服务不依赖本地模型、SQLite 或 Runtime。独立 `agent/node` 复用模型协议与 Agent 核心；连接器可独立接入外部程序，附明确标注固定回答的最小示例。本机独立 Agent 与云端 Web 的文字、图片私聊已通过真实模型验证，远端二进制恢复/撤权联调及模拟检查分别见[节点验证](../validation/README.md#云端-ai-节点验证)，依赖边界由脚本检查。

## 保留待迁入的本地能力

以下功能在先前的本地版本中已实现，代码仍用于回归和后续迁入，当前云端界面尚未提供：

| 主题 | 已有本地实现 | 计划 |
| --- | --- | --- |
| AI 管理扩展 | 普通管理员授权、只读账号视角、图形模型设置与目录同步；云端基础账号/节点与回复已实现 | 第 4 步 |
| 意识系统 | 显式记忆、分段摘要、共同群话题接续、来源失效及上下文组装 | 第 3 步第二批；摘要改为每个 AI 各自维护 |
| 参与和约定 | 有限自动接话、额度、暂停与结束交谈、一次性约定联系及免打扰 | 第 3 步第三批 |
| 数据 | SQLite 顺序迁移、目录锁、显式历史导入、现有聊天和意识资料 | 第 5 步迁移；原库保留 |

先前 Windows 日常流程验收及安装更新只证明当时的本地版本。新版云端客户端没有借用这些记录声称完成平台或安装验收。社交执行仍未开放通用工具、MCP 或插件。
